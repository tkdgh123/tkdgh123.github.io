LMS 마감 알림

숭실대 LMS 과제·영상 마감을 매일 아침 휴대폰으로, 노트북을 켤 때마다 화면으로 알려 줘요. 이미 낸 과제와 다 본 영상은 빠져요.

오늘 마감 내일 마감 이번 주 2026.10.31 시작

하루에 언제 오나

08:00휴대폰 알림7일 안의 마감 목록
하루 한 번
노트북 켤 때마감 창로그인하면 바로
잠금 풀 때또 마감 창오늘·내일 마감이 남았으면
1시간에 한 번
오늘·내일 마감 있으면카톡도아침 알림 때 같이

알림 세기

D-0가장 센 알림

아주 긴 진동과 함께 화면 위에 떠요

D-1높은 알림

긴 진동과 알림음, 화면 위에 떠요

D-2+보통 알림

짧은 진동과 기본 알림음

마감을 어떻게 가져오나

1LMS 토큰

내가 LMS 설정에서 만든 열쇠. 비밀번호는 저장하지 않아요

2과목 목록

이번 학기 듣는 과목을 LMS에서 받아요

3주차학습 열기

사람이 주차학습 탭을 누르듯 열어서 2시간짜리 출석 토큰을 받아요

4과제·영상 모으기

과목마다 과제·퀴즈·토론과 강의 영상의 마감일을 읽어요

5할 것만 남기기

낸 과제, 다 본 영상, 지난 마감은 빼고 마감 순으로 정렬

과제·퀴즈·토론제출했는지 함께 와요/learningx/api/v1/courses/{과목}/allcomponents_db
강의 영상출석 인정 마감과 다 봤는지 함께 와요/learningx/api/v1/courses/{과목}/modules?include_detail=true

이렇게 정한 이유

휴대폰은 ntfy 앱

카톡 나와의 채팅
ntfy 푸시: 진짜 알림음, 가입 없음, 무료

로그인은 토큰으로

학번·비밀번호 저장
LMS 토큰 하나. 설정에서 지우면 바로 끊겨요

노트북은 크롬 앱 창

파이썬 기본 창 (꾸미기 어려움)
웹페이지처럼 그린 창. 카드를 누르면 그 과제로 바로 가요

관리

바로 써 보기

python lms_alert.py --show지금 목록을 창으로
python lms_alert.py --test휴대폰으로 시험 알림
python lms_alert.py setup토큰 다시 붙여 넣기
schtasks /Change /TN "LMS 마감 알림" /DISABLE잠시 끄기

파일

  • lms_alert.py가져오기·알림
  • lms_alert.html노트북 창 디자인
  • .lms_alert.json토큰·알림 주소 (공개 금지)
  • .lms_alert.log언제 무엇을 보냈는지
  • 작업 스케줄러8시 · 로그인 · 잠금 해제

연결이 끊기면 창과 휴대폰에 알려 줘요. 그때 Claude에게 "LMS 다시 연결해".
