01 · 두 번째 릴스

게임 개발 스킬 77개gamedev-skills/awesome-gamedev-agent-skills깔아 볼 만함

영상이 말한 것

스킬 77개로 Claude Code가 게임 개발자가 된다. 엔진과 할 일을 알아서 골라 스킬을 쓰고, 아트 방향을 맞추고, Steam·App Store 출시까지 돕는다.

저장소에서 확인한 것

맞아요. 스킬마다 엔진 버전이 박혀 있고, router 스킬이 프로젝트 파일로 엔진을 알아내 필요한 것만 불러와요. 다만 출시 스킬은 Steam·itch.io뿐이고 App Store 스킬은 없어요.

49엔진 스킬 (Unity 8 · Godot 16 · 웹 6 …)
15공통 기술 (손맛·카메라·저장·아트 방향 …)
9 + 4장르 + 작업 흐름
★7.6kApache-2.0 · 10.28 마지막 수정

이 노트북에선

  • Unity 스킬이 딱 맞는 버전이에요. 스킬 기준은 Unity 6.3 LTS(6000.3), 넋굿·마디는 6000.3.26f1이에요.
  • 쓸 데가 바로 있어요. 마디의 unity-animation(휴머노이드 IK), 퍼즐 데모의 game-feel·puzzle, 브라운 로그의 pygame 스킬, 넋굿의 roguelike.
  • 평소엔 거의 안 무거워요. 스킬은 짧은 설명만 늘 떠 있고, 본문은 필요할 때만 읽혀요.

설치 (Unity만 쓸 때)

claude plugin marketplace add gamedev-skills/awesome-gamedev-agent-skills
claude plugin install router@awesome-gamedev-agent-skills
claude plugin install unity@awesome-gamedev-agent-skills
전부 깔려면 마지막 두 줄 대신  claude plugin install gamedev@awesome-gamedev-agent-skills
02 · 첫 번째 릴스

헤드룸headroomlabs-ai/headroom (옛 chopratejas/headroom)한 번 시험

영상이 말한 것

도구 출력·로그를 클로드에 닿기 전에 걸러서 20분의 1로 줄인다. 데이터 덩어리는 최대 95%까지 줄고 답은 그대로다.

저장소에서 확인한 것

내 컴퓨터에서 도는 중계기예요. 실제 측정은 입력 21~57% 감소(작업 4종)이고, 90% 넘게 줄어드는 건 같은 모양 JSON·로그가 반복될 때뿐이에요. 글이나 코드는 조금밖에 안 줄어요. 정답률은 차이가 오차 안이었어요.

21–57%저장소가 잰 입력 감소 (작업 4종)
~20%코딩 에이전트에서의 대표값
1/20영상 수치 = 반복 데이터일 때 최대치
★79kApache-2.0 · 오늘도 수정 중

이 노트북에선

  • 구독 한도에 여유가 생기는 쪽이에요. 돈이 아니라 사용량 한도가 덜 차요. 다만 우리 작업은 대부분 코드·글이라 20% 안팎을 기대하는 게 맞아요.
  • 켜 두면 꺼지는 기능이 있어요. 중계기를 거치면 Claude Code의 Remote Control을 못 써요.
  • 같이 깔리는 게 있어요. 코드 탐색 도구 Serena가 그 프로젝트에 등록되고, 익명 사용 통계가 기본으로 켜져 있어요.
  • 이 노트북에서 아직 돌려 보지 않았어요. 실제로 얼마나 줄지는 headroom savings로 재야 알아요.

시험해 보기 (PowerShell, 한 세션만)

uv tool install --python 3.13 "headroom-ai[all]"
$env:HEADROOM_TELEMETRY = "off"
headroom wrap claude --code-memory none
끝나고 얼마나 줄었는지  headroom savings
되돌리기  headroom unwrap claude

uv는 이미 깔려 있어요. wrap은 그 창에서만 중계기를 켜고, Claude를 끄면 같이 꺼져요.

03 · 첫 번째 릴스

태스크 옵저버rebelytics/one-skill-to-rule-them-all지금은 보류

영상이 말한 것

내가 클로드 결과물을 고칠 때마다 옆에서 기록하고, 같은 잔소리를 반복하지 않게 스킬 고칠 점을 제안한다. 바꿀지는 내가 고른다.

저장소에서 확인한 것

맞아요. 고친 것·반복하는 일을 기록해 스킬 수정안과 새 스킬 후보를 내고, 승인 전엔 아무것도 안 바꿔요. 깔기만 해선 안 켜지고 CLAUDE.md에 켜기 문구를 넣어야 해요.

보류하는 이유

  • 같은 일을 이미 하고 있어요. 지적받은 걸 규칙으로 남긴 기억 파일이 17개 있고, 세션마다 읽혀요.
  • 저장소도 그렇게 말해요. 스킬이 적은 작은 환경에선 기본 기억 기능으로 충분할 수 있다고 적혀 있어요.
  • 토큰을 더 써요. 세션마다 관찰하고 기록하는 몫이 붙어서, 헤드룸으로 아끼려는 것과 방향이 반대예요.
  • 내가 만든 스킬이 여러 개로 늘고, 같은 지적을 여러 프로젝트에서 반복하게 되면 그때 다시 볼 만해요.

나중에 깔 때

npx skills add rebelytics/one-skill-to-rule-them-all --skill task-observer -g
