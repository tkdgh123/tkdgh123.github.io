01준비 — 처음 한 번만

무료인 Visual Studio Community를 깐다. 설치 화면의 "워크로드"에서 C++를 사용한 데스크톱 개발에 체크한다 (C 컴파일러가 여기 들어 있다). 이미 깔려 있으면 이 단계는 건너뛴다.

02코드 받기

둘 중 편한 쪽으로.

가) 프로젝트째 받기 — deolmi_vs.zip 받기 를 받아 압축을 푼다. 안에 deolmi.c, deolmi.sln, deolmi.vcxproj 세 개가 있다. deolmi.sln을 더블클릭하면 Visual Studio로 열린다.

나) 내 프로젝트에 넣기 — Visual Studio에서 새 프로젝트 → 빈 프로젝트를 만들고, deolmi.c 받기 로 받은 파일을 솔루션 탐색기의 "소스 파일"에 끌어다 넣는다.

따로 설정할 것은 없다. 한글이 깨지지 않게 하는 설정은 코드 안에 들어 있다.

03켜기 — F5

Visual Studio에서 F5(또는 Ctrl+F5)를 누르면 빌드되고 창이 뜬다. 창에서 세 가지를 묻는다.

이름 (한글 5글자까지): 창식 1. 방장 2. 참가자 : 1 덜미 - 창식 (방장) [주소] 192.168.0.5 (같은 와이파이에서 이 주소로 접속) 명령어: /dm 이름(1:1 대화), /all(전체 대화), /who(접속자 보기), /quit(나가기)

2를 고르면 "방장 주소"를 하나 더 묻는다. 이름이 잘못됐거나 접속이 안 되면 처음부터 다시 묻는다.

04혼자 먼저 해 보기 — 노트북 한 대

03에서 켠 창은 방장으로 두고(1), 하나를 더 켠다. 프로젝트 폴더의 x64\Debug\deolmi.exe를 더블클릭하면 같은 질문이 뜬다. 이번엔 2를 고르고 주소는 그냥 엔터(같은 컴퓨터). 아무 글이나 치고 엔터를 누르면 상대 창에 뜬다.

05친구와 채팅 — 노트북 두 대

둘 다 같은 와이파이에 있어야 한다. 한 사람(방장)이 방을 열고, 친구는 2를 골라 방장 화면의 [주소]를 친다. 방장이 곧 서버라서, 셋 이상이어도 모두 같은 주소로 들어온다. 인원 제한은 없다.

방장 노트북 — 처음 한 번만: 처음 방을 열 때 Windows 보안 경고(방화벽) 창이 뜬다. 개인 네트워크와 공용 네트워크를 둘 다 체크하고 액세스 허용을 누른다. 학교 와이파이나 핫스팟은 보통 "공용"이라서, 공용을 빼면 친구가 못 들어온다.

실수로 취소를 눌렀으면: 설정 → 개인 정보 및 보안 → Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용 → deolmi 를 찾아 개인·공용을 켠다.

실제로 돌려 본 화면

Visual Studio에서 켠 방장 창식과, exe를 더블클릭해 들어온 철수의 실제 화면이다 (주소만 예시로 바꿨다). 철수는 처음에 이름에 띄어쓰기를 넣어서 다시 질문을 받았다. 색이 다른 줄이 직접 친 것이다.

06대화 명령

치는 것하는 일
그냥 글방에 있는 모두에게
/dm 이름그 사람하고만 1:1
/all다시 모두에게
/who지금 들어와 있는 사람
/quit나가기 (Ctrl+C나 창 닫기도 된다)

방장이 나가면 방이 닫힌다. 방장은 남들끼리의 1:1도 중계하므로, 암호화 전인 지금은 방장 컴퓨터에서 내용을 볼 수 있다.

07막히면

  • F5를 눌렀는데 빌드가 안 됨 → 01의 "C++를 사용한 데스크톱 개발"을 안 깐 것이다 (Visual Studio Installer → 수정).
  • …에 접속하지 못했습니다 → 방장이 아직 방을 안 열었거나 주소가 틀렸다. 방장을 먼저 켠다. 방장 노트북의 방화벽도 확인한다 (05). 친구 노트북 PowerShell에서 Test-NetConnection 192.168.0.5 -Port 9000 의 TcpTestSucceeded 가 True 여야 한다.
  • 그래도 안 됨 → 학교·카페 와이파이는 기기끼리 연결을 막는 경우가 많다. 한 사람 휴대폰 핫스팟에 둘 다 연결하고 방을 다시 연다. 바뀐 주소가 [주소] 줄에 뜬다.
  • 9000번 포트로 방을 열 수 없습니다 → 이미 켜 둔 덜미 방장이 있다. 그 창을 닫는다 (안 보이면 명령 프롬프트에서 taskkill /im deolmi.exe).
  • 이름을 다시 물음 → 이름은 한글 5글자(15바이트)까지, 띄어쓰기와 / 없이. 이미 들어와 있는 이름이나 방장 이름도 안 된다.
