01우분투 준비 — 처음 한 번만

덜미는 우분투(리눅스) 창에서 돌린다. 윈도우에서는 WSL로 윈도우 안에 우분투를 깐다.

# ① 시작 버튼 오른쪽 클릭 → "터미널(관리자)" 를 열고 wsl --install -d Ubuntu-24.04 # ② 재부팅 → 시작 메뉴에서 "Ubuntu" 를 켠다. 처음이면 사용자 이름(영어 소문자)·비밀번호를 정한다 # ③ 그 우분투 창에서 컴파일러 설치 (비밀번호를 물으면 ②에서 정한 것) sudo apt update && sudo apt install -y build-essential

이미 우분투가 깔려 있으면 시작 메뉴에서 Ubuntu 를 켜고 ③만 하면 된다. 맥은 터미널에서 xcode-select --install (맥에서는 아직 직접 돌려 보지 못했다).

02코드 받기 — 우분투 창에서

deolmi.c 파일 하나가 프로그램 전부다. 우분투 창에 아래를 그대로 친다. 홈 폴더(~)로 받는다.

cd ~ curl -O https://tkdgh123.github.io/secure-msg/code/src/deolmi.c # 진행 표시가 100 까지 차면 끝. 코드가 바뀌면 이 줄을 다시 치면 새것으로 덮어쓴다

브라우저로 받고 싶으면 deolmi.c 받기 — 윈도우 다운로드 폴더에 들어가고, 우분투에서는 cd /mnt/c/Users/윈도우이름/Downloads 로 간다.

03빌드

gcc -o deolmi deolmi.c # 아무 말 없이 끝나면 성공. deolmi 라는 실행 파일이 생긴다. 이제 ./deolmi 로 켠다

다음에 다시 켤 때는 우분투를 열고 cd ~ 한 뒤 바로 ./deolmi … 하면 된다.

04혼자 먼저 해 보기 — 노트북 한 대

우분투 창을 두 개 연다. 하나는 방을 여는 방장, 하나는 들어오는 참가자. 같은 컴퓨터면 주소를 안 써도 된다.

# 창 1 — 방장 (방을 열고, 자기도 대화한다) ./deolmi 민지 --host # 창 2 — 참가자 ./deolmi 현우

Windows Terminal에서는 Alt+Shift+D 로 창을 나누면 한 화면에서 둘 다 보인다. 아무 글이나 치고 엔터를 누르면 상대 창에 뜬다.

05친구와 채팅 — 노트북 두 대

둘 다 같은 와이파이에 있어야 한다. 한 사람(방장)이 방을 열고, 친구가 그 노트북 주소로 들어온다.

방장 노트북 — 처음 한 번만 할 일

WSL은 기본 설정이면 바깥에서 들어오는 연결을 받지 못한다. 그래서 방장 노트북만 두 가지를 해 둔다. (참가자 노트북은 01~03만 하면 된다.)

① 미러링 — 메모장으로 C:\Users\이름\.wslconfig 파일을 만들고 아래 두 줄을 넣는다. 저장한 다음 PowerShell에서 wsl --shutdown 하고 우분투를 다시 켠다. (윈도우 11 22H2 이상)

[wsl2] networkingMode=mirrored

② 방화벽 열기 — 관리자 PowerShell에서 한 번만 실행. 덜미가 쓰는 9000번 포트로 들어오는 연결을 허용한다.

New-NetFirewallHyperVRule -DisplayName "덜미 9000" -Direction Inbound ` -VMCreatorId "{40E0AC32-46A5-438A-A0B2-2B479E8F2E90}" ` -Protocol TCP -LocalPorts 9000 -Action Allow

채팅할 때마다

# 1. 방장 — 방 열기 (우분투). 친구가 칠 명령이 주소까지 붙어서 뜬다 ./deolmi 민지 --host [주소] 192.168.0.5 — 다른 컴퓨터는 ./deolmi 이름 192.168.0.5 으로 들어와요 # 2. 친구 — 그 명령에서 "이름"만 자기 이름으로 바꿔 친다 (친구 노트북 우분투) ./deolmi 현우 192.168.0.5

실제로 돌려 본 화면

두 프로그램을 띄워 실제로 주고받은 화면이다 (주소만 예시로 바꿨고, /who 줄과 시작할 때 뜨는 사용법 설명은 줄였다). 민지> 로 시작하는 줄이 내가 친 것이다.

07셋 이상이거나 서버를 따로 두고 싶을 때

방장 대신 중계만 하는 서버를 띄울 수도 있다. 서버 창에는 오가는 패킷이 한 줄씩 찍힌다 (지금은 암호화 전이라 내용이 그대로 보인다). 서버 노트북이 05의 "처음 한 번만 할 일"을 해 둔다.

./deolmi --server # 서버 노트북 ./deolmi 민지 192.168.0.5 # 나머지는 모두 참가자로, 서버 주소를 쓴다 ./deolmi 현우 192.168.0.5

한 방에 16명까지 들어온다.

08막히면

  • → 그 주소에 열린 방이 없어요 → 방장(서버)이 아직 안 켰거나 주소가 틀렸다. 방장을 먼저 켠다.
  • → 연결이 중간에서 막혔어요 (5초 기다린 뒤 뜸) → 방장 노트북의 ①미러링 ②방화벽을 확인한다. 친구 윈도우 PowerShell에서 Test-NetConnection 192.168.0.5 -Port 9000 의 TcpTestSucceeded 가 True 여야 한다.
  • 그래도 안 됨 → 학교·카페 와이파이는 기기끼리 연결을 막는 경우가 많다. 한 사람 휴대폰 핫스팟에 둘 다 연결하고 방을 다시 연다. 바뀐 주소가 [주소] 줄에 뜬다.
  • bind: Address already in use → 이미 켜 둔 덜미가 있다. 그 창을 닫거나 pkill -x deolmi.
  • 이름이 거절됨 → 이름은 한글 5글자(15바이트)까지, 띄어쓰기와 / 없이. 이미 들어와 있는 이름도 안 된다.
