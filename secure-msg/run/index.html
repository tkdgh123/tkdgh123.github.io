01준비 — 처음 한 번만

무료인 Visual Studio Community를 깐다. 설치 화면의 "워크로드"에서 C++를 사용한 데스크톱 개발에 체크한다 (C 컴파일러가 여기 들어 있다). 이미 깔려 있으면 이 단계는 건너뛴다.

02코드 받기

프로젝트째 받는다. 암호 라이브러리 설정까지 들어 있어서 새 빈 프로젝트에 deolmi.c만 넣으면 빌드되지 않는다.

deolmi_vs.zip 받기 를 받아 압축을 푼다. 안에 deolmi.c, deolmi.sln, deolmi.vcxproj, 암호 라이브러리 libsodium 폴더, 카메라 지킴이 eye 폴더와 카메라 준비.bat이 있다. deolmi.sln을 더블클릭하면 Visual Studio로 열린다.

따로 설치·설정할 것은 없다. libsodium(1.0.22 공식 빌드)과 그 경로, 한글 설정이 묶음에 다 들어 있다.

03켜기 — F5

Visual Studio에서 F5(또는 Ctrl+F5)를 누르면 빌드되고 창이 뜬다. 창에서 세 가지를 묻는다.

이름 (한글 5글자까지): 창식 1. 방장 2. 참가자 : 1 덜미 - 창식 (방장) [주소] 192.168.0.5 (같은 와이파이에서 이 주소로 접속) [내 단어] 물감-민들레-은행잎-하늘-은행잎-사자-양궁-트럭 (신원 키를 새로 만들었습니다) 명령어: /dm 이름(1:1 대화), /all(전체 대화), /who(접속자), /ok 이름(승인), /verify 이름(단어), /check(장부 대조), /eye(카메라 지킴이 켜고 끄기), /trace 새어 나간 줄(누구 화면인지 찾기), /quit(나가기) [알림] 받은 글은 사람마다 띄어쓰기가 조금씩 다르게 보입니다 · 캡처가 새면 보낸 사람이 /trace로 누구 화면인지 찾습니다

[내 단어]는 내 신원 키를 단어 8개로 바꾼 것이다. 처음 켤 때 키를 만들어 %USERPROFILE%\.deolmi\이름\에 두고, 같은 이름으로 켜면 늘 같은 단어가 나온다. 2를 고르면 "방장 주소"를 하나 더 묻는다. 이름이 잘못됐거나 접속이 안 되면 처음부터 다시 묻는다. 마지막 [알림]은 유출 추적 때문에 받은 글의 띄어쓰기가 사람마다 조금씩 다르게 보인다는 안내다 (아래 06).

04혼자 먼저 해 보기 — 노트북 한 대

03에서 켠 창은 방장으로 두고(1), 하나를 더 켠다. 프로젝트 폴더의 x64\Debug\deolmi.exe를 더블클릭하면 같은 질문이 뜬다. 이번엔 2를 고르고 주소는 그냥 엔터(같은 컴퓨터). 방장 창에 [입장 심사] … 들어왔습니다 · 단어 …가 뜨면, 참가자 창의 [내 단어]와 같은지 보고 방장 창에 /ok 이름을 친다. 그다음부터 아무 글이나 치고 엔터를 누르면 상대 창에 뜬다.

승인하기 전에 방장이 친 글은 참가자에게 가지 않는다 (아직 대화할 멤버가 없습니다). 셋 이상이면 기존 멤버 모두가 /ok 해야 새 사람이 들어온다.

05친구와 채팅 — 노트북 두 대

둘 다 같은 와이파이에 있어야 한다. 친구가 들어오면 친구에게 직접(옆에서, 전화로) 단어를 물어보고 맞으면 /ok 이름 — 그래야 엉뚱한 사람이나 몰래 붙은 기기가 대화를 못 본다. 한 사람(방장)이 방을 열고, 친구는 2를 골라 방장 화면의 [주소]를 친다. 방장이 곧 서버라서, 셋 이상이어도 모두 같은 주소로 들어온다. 인원 제한은 없다.

방장 노트북 — 처음 한 번만: 처음 방을 열 때 Windows 보안 경고(방화벽) 창이 뜬다. 개인 네트워크와 공용 네트워크를 둘 다 체크하고 액세스 허용을 누른다. 학교 와이파이나 핫스팟은 보통 "공용"이라서, 공용을 빼면 친구가 못 들어온다.

실수로 취소를 눌렀으면: 설정 → 개인 정보 및 보안 → Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용 → deolmi 를 찾아 개인·공용을 켠다.

실제로 돌려 본 화면

11-06 저녁 최종 버전을 한 노트북에서 둘로 띄운 실제 출력이다 (주소만 예시, 명령어 안내 줄은 03과 같아서 뺐다). 색이 다른 줄이 직접 친 것이다. 민지가 들어오자 창식 화면에 입장 심사가 뜨고, 창식이 단어를 확인해 /ok 하자 대화가 열린다. 민지 화면의 창식 글에 두 칸 띄운 곳이 있는 게 띄어쓰기 표식이다 (다른 사람 화면에선 다른 곳이 두 칸). 마지막 /check는 둘이 같은 대화를 받았는지 장부로 맞춰 본 것이다.

06대화 명령

치는 것하는 일
그냥 글멤버 모두에게 (사람마다 따로 암호화해서 보낸다)
/dm 이름 · /all그 사람하고만 1:1 · 다시 모두에게
/who지금 있는 사람 (승인 전이면 "승인 대기")
/ok 이름새로 온 사람 승인. 단어를 직접 물어보고 맞을 때만
/verify · /verify 이름내 단어 · 그 사람 단어 보기
/check지금 바로 모두와 장부 대조 (같은 대화를 받았나)
/eye카메라 지킴이 켜기 · 끄기 (아래 "화면 지키기")
/trace 새어 나간 줄내가 보낸 글이 새어 나왔을 때, 그 줄을 붙여 넣으면 누구 화면인지 찾음
/quit나가기 (Ctrl+C나 창 닫기도 된다)

방장이 나가면 방이 닫힌다. 방장은 남들끼리의 글도 중계하지만 암호문만 넘기므로 열어 볼 수 없다.

/tamper 민지방장민지에게 가는 다음 글을 1바이트 바꿈 → [!] … 중간에 바뀌었습니다 · 버림

장부 대조는 셋 이상일 때 의미가 있다. 시연은 노트북 한 대에서 창 넷(방장 + 셋)으로 해도 된다.

화면 지키기 — 찍으면 가려지고, 새면 잡힌다

카메라 지킴이 준비 — 처음 한 번만: 받은 deolmi 폴더의 카메라 준비.bat을 더블클릭한다. python이 없으면 알아서 깔고(관리자 권한 필요 없음), 휴대폰 인식에 쓰는 mediapipe를 받는다. 인터넷이 필요하고 처음엔 몇 분 걸린다. [카메라 준비] 끝이 뜨면 아무 키나 눌러 닫는다. 덜미의 다른 기능은 이게 없어도 된다.

  1. 한 창에서 /eye → 몇 초 뒤 [카메라] 켜졌습니다. 다른 창들에는 … 카메라 지킴이를 켰습니다.
  2. 노트북 카메라 앞에서 휴대폰을 들어 화면 쪽으로 향한다 → 그 창의 글이 사라지고 경고만 남는다. 다른 창에는 [덜미] ○○ 화면 앞에 휴대폰이 보입니다. 휴대폰을 내리면 원래대로 돌아온다.
  3. 손가락으로 카메라를 1초 넘게 가린다 → 똑같이 가려지고 다른 창에 [덜미] ○○의 카메라가 가려졌습니다.
  4. 유출 추적 — 민지가 긴 글을 보낸 뒤, 현우 창에서 그 줄을 마우스로 드래그해 복사한다. 민지 창에 /trace 를 치고 붙여 넣으면 사람마다 어떻게 보였는지 줄줄이 나오고 [추적] 현우 화면에서 나온 글입니다.

글이 길수록(띄어쓰기가 많을수록) 정확하다. 캡처 사진이 새어 나왔으면 /trace에 글만 대충 쳐도 사람마다의 줄이 나오니, 사진과 띄어쓰기를 눈으로 비교한다. 복사가 안 되면 Shift를 누른 채 드래그하거나 창 메뉴의 "편집 → 표시"를 쓴다.

07막히면

  • F5를 눌렀는데 빌드가 안 됨 → 01의 "C++를 사용한 데스크톱 개발"을 안 깐 것이다 (Visual Studio Installer → 수정).
  • …에 접속하지 못했습니다 → 방장이 아직 방을 안 열었거나 주소가 틀렸다. 방장을 먼저 켠다. 방장 노트북의 방화벽도 확인한다 (05). 친구 노트북 PowerShell에서 Test-NetConnection 192.168.0.5 -Port 9000 의 TcpTestSucceeded 가 True 여야 한다.
  • 그래도 안 됨 → 학교·카페 와이파이는 기기끼리 연결을 막는 경우가 많다. 한 사람 휴대폰 핫스팟에 둘 다 연결하고 방을 다시 연다. 바뀐 주소가 [주소] 줄에 뜬다.
  • 9000번 포트로 방을 열 수 없습니다 → 이미 켜 둔 덜미 방장이 있다. 그 창을 닫는다 (안 보이면 명령 프롬프트에서 taskkill /im deolmi.exe).
  • 내 글이 상대에게 안 감 → 아직 승인 전이다. 방장과 기존 멤버가 모두 /ok 이름 해야 한다. /who로 "승인 대기"인지 본다.
  • [!] ○○의 키가 전과 다릅니다 → 그 사람이 다른 노트북으로 왔거나 신원 키 폴더를 지웠으면 정상이다. 단어를 다시 물어보고 맞으면 /ok. 아니면 다른 사람이다.
  • [카메라] 카메라 프로그램이 멈췄습니다 → 아직 카메라 준비.bat을 안 돌렸다 (06 "화면 지키기"). 돌렸는데 [실패]가 떴으면 인터넷을 확인하고 다시 돌린다.
  • [카메라] 카메라를 열지 못했습니다 → 줌·팀즈 같은 다른 프로그램이 카메라를 쓰고 있거나, 윈도우 설정 → 개인 정보 및 보안 → 카메라에서 "데스크톱 앱이 카메라에 액세스하도록 허용"이 꺼져 있다.
  • [추적] 띄어쓰기가 꼭 맞는 사람이 없습니다 → 내가 보낸 글이 아니거나, 누가 다시 타이핑해서 띄어쓰기가 바뀌었다. 나온 줄들과 눈으로 비교해 본다.
  • 이름을 다시 물음 → 이름은 한글 5글자(15바이트)까지, 띄어쓰기와 / | 없이. 이미 들어와 있는 이름이나 방장 이름도 안 된다.
