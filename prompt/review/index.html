평가 기록 · 2026년 11월 15일

프롬프트 연습 평가

연습은 돼요. AI에게 학생 역할을 맡겨 재 보니, 연습한 쪽이 처음 보는 문제에서 첫 말이 평균 22점 높았어요. 하지만 채점하려면 계정이나 키가 있어야 하고, 문제가 10개뿐이며, 낱말만 나열해도 만점 가까이 나와요. 지금은 잘 만든 무료 연습장이고, 바로 돈이 되는 제품은 아니에요.

직접 돌린 채점 325판, 학생 역할 AI 10명의 풀이, 웹 조사, 다른 AI(Codex)의 코드 검토를 합쳤어요. 점수는 Claude가 매겼어요. 프롬프트 연습 열기

지표별 점수

10점 만점. 4점 이하는 빨강. 근거가 된 숫자는 아래 칸에 있어요.

지표근거점수

진짜 연습이 되나

사람 대신 Claude Haiku에게 '프롬프트를 거의 써 본 적 없는 1학년' 역할을 맡겨 실제 화면과 같은 정보만 주고 풀게 했어요. 문제 설명, 자료 글, 붙일 수 있는 첨부, 결과 예상이 전부예요. 채점은 화면과 똑같은 채점기(노트북 Sonnet)가 했어요.

  • 연습 없음 5명: 시험 문제 4개(밤새 버그 맡기기, 포트폴리오, 따릉이 분석, AI 협업 코딩 시험)를 바로 풀었어요.
  • 연습함 5명: 다른 문제 4개(동아리 모집, MT 신청, 자기소개서, 팀플 정리)를 먼저 풀고, 문제마다 채점·돌아보기·모범 답안을 본 뒤 '배운 점'을 8줄 안으로 적었어요. 그 메모만 들고 같은 시험 문제 4개를 풀었어요.

처음 보는 문제의 첫 말 점수

연습 없음연습함점 하나 = 한 사람, 세로 막대 = 평균

연습함 무리는 첫 말 평균 79.8점, 연습 없음 무리는 57.7점이었어요. 차이는 포트폴리오(+37)·따릉이 분석(+28)·밤새 맡기기(+17)에서 컸고, 원래 쉬웠던 코딩 시험(+5)에서 작았어요. 이어 말하기까지 끝낸 마지막 점수는 82.3과 81.5로 거의 같았어요. 문제마다 5명씩이라 큰 흐름만 보면 돼요.

한 판 안에서 고쳐 가기

결과 예상을 보고 이어 말하면 점수가 오르는지 봤어요. 보낸 말은 최대 3번이에요.

시험 문제연습 없음 첫 말 → 마지막연습함 첫 말 → 마지막

연습한 학생이 적은 배운 점 (한 명의 메모 그대로)

1. 부탁 전에 근거 자료(공지, 대화, 보고서, 메모)를 빠짐없이 붙인다. 2. 결과물이 어디서 어떻게 보일지(메신저, 폰, 링크, 공유 방식)를 한 줄로 적고, 길이도 "붙여 넣을 만큼 짧게"처럼 정한다. 3. 원본과 달라진 정보(날짜, 담당, 장소, 연락처)와 틀린 사실은 따로 짚어 주고, 이어서 고칠 때도 원문과 맞는지 먼저 확인한다. 4. 자료에 없는 후기, 수치, 경험은 지어내지 말라고 처음부터 적는다. 5. 정해지지 않은 항목은 가짜로 채우지 말고 [ ]로 비우되, "○○으로 따로 표시"처럼 상태 이름을 붙여 남긴다. 6. 개인정보나 민감한 사정은 넣을지 말지, 문의를 어디로 받을지 명시한다. 7. 원하는 결과물(모일 곳, 형식, 순서, 분량)을 직접 말하고, 조건은 줄로 나눠 빠짐없이 적는다. 8. 고칠 땐 "○○만 바꿔 줘"처럼 바꿀 부분을 콕 집고, 뻔한 문장은 빼 달라고 한다.

채점을 믿을 수 있나

같은 말을 여러 번 채점해 높아야 할 말은 높게, 낮아야 할 말은 낮게, 판마다 흔들리지 않는지 봤어요. 모두 노트북 Sonnet 채점이에요.

결과 예상이 답을 흘리는지

막연한 한 줄 50판의 결과 예상을 숨은 사실 낱말로 훑었어요. 자기소개서는 틀린 사실이 그대로 남은 글을, 밤새 맡기기는 작업 중 파일까지 고친 보고를 보여 줬어요. 둘 다 학습자가 비교해 찾아야 할 모습이라 괜찮아요.

문제는 AI 협업 코딩 시험이에요. 5판 중 4판이 "김하늘의 합계에는 취소된 1003번 주문 15,000원이 들어 있어요"처럼 무엇이 틀렸는지 짚어 줬어요. 11월 15일에 결과 예상을 더 분명하게 바꾸면서 생긴 일로 보여요. 출력만 보여 주고 계산은 학습자가 하게 해야 연습이 돼요.

시장에서 설 자리

수요 신호 (출처를 직접 열어 확인한 것)

  • CJ올리브네트웍스는 2026년 하반기 신입 공채에서 코딩테스트를 'AI 역량진단'으로 바꿨어요. 개발 직무는 AI와 함께 결과물을 만드는 바이브코딩 테스트, 비개발 직무는 업무에서 AI를 쓰는 테스트예요(보도자료 9월 17일).
  • 교육부·대교협의 2026 대학 AI 기본교육과정 사업은 20개 대학에 대학당 3억 원을 주고, AI 기초 교양을 2개 이상 만들어 1개 이상을 신입생 필수로 하게 했어요(2월 23일 발표).
  • Anthropic의 AI Fluency 강의에도 '위임' 단원이 있지만, 학습자가 쓴 말을 자동 채점하는 기능은 없어요.

넥슨·크래프톤·HD현대·두산 등도 AI 활용 역량 평가를 넣었다는 기사가 있지만 한 번씩만 확인했어요. "기업 69.2%가 채용 때 AI 역량을 본다"는 대한상의 수치는 원자료를 못 찾았어요.

한국어로 쓴 말을 AI가 자동 채점해 주는 연습 서비스, 그리고 코딩 에이전트에게 일 맡기기를 연습시키는 서비스는 이번 검색에서 찾지 못했어요. 못 찾았다는 것이지 없다는 뜻은 아니에요.

앞서는 점

  • 한국어, 그리고 대학생이 실제로 겪는 상황(동아리·MT·자소서·따릉이 과제·팀플·코딩 시험)이에요.
  • 쓰고 → 결과를 보고 → 고치고 → 채점·돌아보기까지 한 바퀴가 몇 분이에요. 강의형 경쟁작에는 이 바퀴가 없어요.
  • '일을 맡기는 말'에 모여 있어 기업의 AI 활용 평가와 결이 같아요.
  • 운영비 0원. 각자 계정·키로 채점해요.

밀리는 점

  • 실제로 실행하지 않고 AI가 결과를 예상해요. 예상이 틀리면 채점도 틀려요.
  • 채점하려면 claude.ai 계정(아티팩트, 지금은 비공개 링크)이나 API 키가 있어야 해요. 키 만들기는 비개발자에게 큰 문턱이에요.
  • 문제가 10개뿐이고, 다시 풀면 숨은 항목을 외워서 만점이 돼요.
  • 자격·인증이 아니라 이력서에 쓸 거리가 되지 않아요. 무료라 돈을 받을 구조도 없어요(개인 구독으로 남을 채점하는 건 약관상 안 돼요).

먼저 고칠 것

  1. 시작 문턱부터 낮추기. claude.ai 아티팩트 링크를 공개하면(공유 메뉴, 만든 사람만 할 수 있어요) claude.ai 계정만 있으면 키 없이 채점돼요. 지금 가장 큰 막힘이에요.
  2. 결과 예상이 틀린 곳을 짚지 않게. 코딩 시험처럼 '취소 주문도 들어 있어요'라고 이유를 쓰지 말고 출력('김하늘 47000')만 보여 줘야, 학습자가 직접 계산해 찾아요.
  3. 낱말 나열을 어떻게 볼지 정하기. 실제 Claude도 낱말만 받아도 꽤 알아듣기 때문에 무조건 깎을 일은 아니에요. 순서·우선순위가 없는 나열은 한 단계 낮추는 규칙을 넣을지 만든 사람이 정할 일이에요.
  4. 다시 풀기용 쌍둥이 문제. 사람 이름·날짜·바뀐 사실만 바꾼 판을 문제마다 하나씩 두면, 숨은 항목을 외워서 받는 만점을 막을 수 있어요.
  5. 사람 학생으로 재기. 친구 5~10명에게 문제 2개를 풀게 하고, 연습 4문제 뒤 새 문제 점수를 보면 AI 흉내가 아닌 진짜 학습 효과가 나와요.

어떻게 쟀나, 무엇을 못 쟀나

  • 채점은 모두 만든 사람 노트북의 Claude Code(Sonnet)로 했어요. 실제 사용자가 쓰는 내 API 키(Opus 5.5)나 claude.ai 계정 채점은 재지 않았어요.
  • 학생은 AI가 흉내 낸 것이에요. AI는 처음부터 말을 꽤 잘 써서 실제 1학년보다 첫 점수가 높을 거예요. 사람 학생으로 잰 결과는 아직 없어요.
  • 한 번 보낼 때 채점기에 가는 글은 6,000~8,200자예요. 내 API 키로 한 문제(보내기 3번+돌아보기)를 풀면 Opus 5.5 요금으로 0.2~0.3달러쯤으로 어림했어요. 토큰을 직접 세지는 않았어요.
  • 화면은 넓은 화면·휴대폰 너비에서 찍어 확인했어요. 화면 읽기 프로그램과 키보드만으로 쓰는 경우는 확인하지 않았어요.
  • Codex에 코드와 화면을 주고 따로 평가받았어요(학습 효과 설계 6, 채점 신뢰도 4, 문제 품질 7, 사용 흐름 7, 기술 완성도 6, 확장성 5). 그 뒤 직접 잰 숫자로 맞는 것만 받아들였어요. 키워드 나열은 Codex 말대로였고, 채점기 속이기는 Codex가 걱정한 것과 달리 막혔어요.
