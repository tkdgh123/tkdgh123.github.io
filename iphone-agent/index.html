아이폰에 말하면
아이폰이 움직이게

시험 전 · 준비 대기

“앱들을 색깔별로 정리해줘”라고 말하면 Claude가 내 아이폰을 직접 조작하는 것이 목표예요. 아이폰 혼자서는 안 되니 노트북을 두뇌로 써요.

쓸 때는 아이폰만 들고 말하면 되지만 노트북은 켜져 있어야 해요. 탈옥은 필요 없어요.

내가 먼저 할 일

  1. 1

    아이폰을 USB로 노트북에 연결

    충전 전용 말고 데이터가 되는 케이블로 연결해요. “이 컴퓨터를 신뢰”가 뜨면 신뢰를 누르고 암호를 입력해요.

  2. 2

    iOS 버전 확인

    설정 › 일반 › 정보 › iOS 버전
  3. 3

    시험용 무료 Apple ID 새로 만들기

    account.apple.com에서 만들어요. 전화번호 인증이 필요할 수 있어요. 아이폰의 기존 계정에서 로그아웃하지는 마세요.

끝나면 Claude에게 “꽂았어, iOS OO”라고 말하기.

Claude가 알려 주면 할 일

  1. 4

    Windows 관리자 허용 누르기

    USB 전달 도구를 설치하고 아이폰을 WSL로 넘길 때 몇 번 떠요.

  2. 5

    아이폰 개발자 모드 켜기

    설정 › 개인정보 보호 및 보안 › 개발자 모드

    페어링 후에 메뉴가 나타날 수 있어요. 켜면 재부팅되니 암호를 한 번 입력해요.

  3. 6

    새 Apple ID 로그인

    비밀번호는 채팅에 쓰지 말고 Claude가 띄운 설치 창에 직접 입력해요. 인증 코드를 요구할 수도 있어요.

Claude가 할 일

  • WSL에 Docker와 iphone-control 설치

    설치 전에 코드부터 읽어요.

  • 아이폰 암호 자동 입력은 끄기

    암호가 노트북에 저장되지 않게 해요.

  • 길게 눌러 끌기 동작 붙이기

    도구에 이 동작이 따로 없어서 직접 만들어야 해요.

걸림돌

  • Windows

    성공 사례를 못 찾았어요. WSL이 USB 전달을 지원하는 것까지만 확인했어요.

  • 7일 만료

    무료 Apple ID 서명은 7일마다 다시 해야 해요. 도구가 자동으로 해 준다고 설명돼 있어요.

  • 보안

    조작 도구가 켜진 동안에는 아이폰의 문자 인증번호까지 읽힐 수 있어요. USB로만 쓰고, 다 쓰면 끄고, 시험 중에는 문자·은행 앱을 열어 두지 않아요.

  • 잠금 화면

    재부팅한 뒤에는 암호를 직접 한 번 입력해야 조작할 수 있어요.
