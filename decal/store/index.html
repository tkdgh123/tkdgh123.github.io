창업실 데칼코마니 하기

데칼코마니를 앱으로

지금 웹 게임 그대로 Capacitor 하나로 감싸 구글 플레이와 앱스토어에 둘 다 내요. 맥은 없어도 되고, 돈은 등록비만 들어요.

  • 25달러구글 플레이 등록비, 한 번
  • 99달러애플 개발자 프로그램, 매년
  • 12명 · 14일구글 첫 출시 전 비공개 테스트
  • 약 5~7주처음부터 두 스토어 출시까지

어떻게 감싸나

한 파일짜리 HTML 게임이라 다시 만들 필요는 없어요. 게임 파일을 앱 안에 넣고 웹뷰로 띄우는 방식이 맞고, 두 스토어를 한 번에 하려면 Capacitor예요.

앱 안의 화면은 지금 폰 브라우저에서 보이는 그대로예요. 판을 긋는 손맛, 접히는 종이, 콤보 막대가 바뀌지 않아요. 바뀌는 건 로그인, 진동, 뒤로 가기처럼 폰과 맞닿는 부분뿐이에요.

방식스토어이 게임에핵심
Capacitor 8플레이 + 앱스토어추천게임 파일을 앱 안에 넣어 오프라인에서도 열림. 진동·로그인 같은 네이티브 기능을 플러그인으로 붙임
TWA (Bubblewrap)플레이만안드로이드만 낼 때크롬이 사이트를 그대로 띄움. 앱스토어는 결국 따로 해야 함
Unity·Flutter로 다시둘 다과함이미 잘 도는 게임을 처음부터 다시 짜는 일

Capacitor 8은 Node 22 이상, Android Studio 2025.2.1 이상이 필요해요. iOS 빌드는 Xcode(맥)가 필요해서 아래처럼 클라우드에서 해요. (공식)

지금 코드에서 막히는 것

  • 구글 로그인 팝업이 앱 안에서 막혀요구글은 앱 속 웹뷰에서 로그인 창을 막아요. 앱에서는 @capacitor-firebase/authentication으로 휴대폰 자체 구글 로그인을 띄우고, 받은 토큰을 지금 쓰는 Firebase에 넘겨요. 같은 계정으로 이어져서 웹 랭킹 기록도 그대로예요. (블로그 기준, 여러 사례가 같음)
  • 애플 로그인도 같이 넣어야 안전해요앱스토어 심사 기준 4.8: 구글 같은 바깥 로그인을 쓰면 이름·이메일만 받고 이메일을 숨길 수 있는 로그인도 함께 줘야 해요. 사실상 Sign in with Apple이에요. (공식)
  • 계정 삭제는 생겼고, 앱에선 다시 확인만 바꿔야 해요두 스토어 모두 앱 안에서 계정을 지울 수 있어야 하고, 구글은 앱 없이 삭제를 요청할 웹 주소도 받아요. 11월 12일부터 랭킹의 '내 기록' 아래 '계정 삭제'가 닉네임·판 기록·랭킹 칸·로그인 계정까지 지우니, 웹 주소는 이 게임 주소를 쓰면 돼요. 다만 로그인한 지 오래되면 구글 팝업으로 한 번 더 확인하는데, 이 팝업도 앱 속 웹뷰에선 막혀서 로그인처럼 휴대폰 구글 로그인으로 바꿔야 해요. (구글, 애플 5.1.1(v))
  • 바깥 주소에서 받아 오는 것들Firebase 코드와 글꼴을 인터넷에서 받아 와요. 앱에 넣어 두지 않으면 오프라인에서 랭킹이 안 뜨고, 앱스토어는 내려받는 코드를 싫어해요(4.7). ../game-fx.js 경로도 앱 폴더에 맞게 바꿔요.
  • "← 창업실" 링크앱 밖으로 나가는 링크라 앱에서는 빼요. 웹사이트를 감싸기만 한 앱으로 보이면 4.2(최소 기능)로 거절돼요.
  • 아이폰은 진동이 안 돼요navigator.vibrate는 아이폰 웹뷰에서 안 돼요. @capacitor/haptics로 바꾸면 두 폰 모두 손에 울리고, 심사에서도 '네이티브 기능'이 돼요.
  • 폰에서만 생기는 일세로 고정, 안드로이드 뒤로 가기(랭킹 닫기 → 게임 멈춤 → 나가기), 전화가 오거나 홈으로 갈 때 음악 멈춤, 앱 아이콘과 처음 뜨는 화면, 개인정보처리방침·문의 페이지.
  • '데모'·'베타'라고 쓰면 거절돼요애플 2.2: 데모·베타·체험판은 앱스토어에 올릴 수 없어요. 앱 이름·설명·화면 어디에도 쓰지 말고, 시험은 TestFlight로 해요. (공식)
  • 문의 페이지엔 바로 연락할 수단이 있어야 해요애플 1.5: 앱과 지원 주소에서 쉽게 연락할 수 있어야 해요. 안내 글만 있는 문의 페이지로 거절된 사례가 있어요. 이메일이나 문의 양식을 둬요.
  • 닉네임이 랭킹에 공개돼요애플 1.2(사용자가 만든 내용): 욕설 거르기, 신고 방법, 연락처가 있어야 해요. 지금은 '운영자' 같은 예약어만 막아요.

구글 플레이

등록비 25달러 한 번 · 안드로이드 폰 필요 · 신규 개인 계정은 12명이 14일 연속 비공개 테스트

  1. Play Console에 개발자로 가입해요. 만 18세 이상, 신용·체크카드, 본명과 신분증, 안드로이드 폰에서 Play Console 앱으로 기기 인증. (공식)
  2. Firebase에 안드로이드 앱을 추가하고 google-services.json을 받아요. 디버그·업로드 키의 SHA-1, 나중엔 Play 앱 서명 SHA-1도 등록해야 스토어에서 받은 앱이 로그인돼요.
  3. Android Studio에서 AAB로 빌드해요. 업로드 키(.jks)와 비밀번호는 잃어버리면 안 돼요. 2026-08-31부터 API 36(안드로이드 16) 이상을 타깃해야 해요. (공식)
  4. 앱 만들기 → 앱 설정: 개인정보처리방침 주소, 앱 액세스(로그인 없이도 플레이), 광고 없음, 콘텐츠 등급 설문, 타깃 연령(13세 이상 권장), 데이터 보안 양식, 계정 삭제 주소.
  5. 스토어 그림: 아이콘 512×512 PNG(1MB 이하), 그래픽 1024×500, 휴대폰 스크린샷 2~8장(세로 9:16, 1080×1920 이상 권장). (공식)
  6. 비공개 테스트에 올리고 테스터 12명이 들어오게 해요. 12명이 14일 연속 남아 있어야 프로덕션을 신청할 수 있어요. 검토는 보통 7일 안. (공식)
  7. 프로덕션 출시 → 국가 선택 → 검토 제출.

앱스토어

99달러 매년 · 맥 없이 Codemagic 무료(월 500분) · 시험엔 아이폰 필요

  1. Apple Developer Program에 가입해요. 2단계 인증이 켜진 애플 계정, 본명(스토어에 판매자 이름으로 보여요). (공식)
  2. App Store Connect → 사용자 및 액세스 → 통합에서 API 키를 만들어요(App Manager). .p8 파일은 한 번만 받을 수 있어요.
  3. 개발자 사이트에서 번들 ID를 만들고 Sign in with Apple을 켠 뒤, App Store Connect에 같은 번들 ID로 새 앱을 만들어요.
  4. Codemagic에 GitHub로 가입해 저장소를 잇고 API 키를 넣어요. 서명 인증서와 프로필은 키로 자동으로 만들어져서 맥이 없어도 돼요. (무료 한도)
  5. 빌드 → TestFlight에 올라오면 아이폰에서 로그인·소리·진동·세로 고정을 확인해요. ITSAppUsesNonExemptEncryption = false를 넣으면 빌드마다 암호화 질문이 안 떠요.
  6. 앱 정보: 게임 › 퍼즐, 개인정보처리방침·지원 주소, 연령 등급 설문, 앱 개인정보(이메일·사용자 ID·닉네임·점수, 계정에 연결됨), 스크린샷 1179×2556 또는 1206×2622 최소 1장. 아이패드를 빼면 아이패드 스크린샷은 안 내도 돼요. (공식)
  7. 심사 제출. 절반 넘게 24시간 안, 90%가 48시간 안에 끝나요. 심사 메모에 햅틱·애플 로그인 같은 네이티브 기능을 적어요. (공식)

PC 브라우저와 인터넷 끊은 상태 둘 다에서 게임이 열리면 끝

두 스토어에서 직접 받아 한 판 하면 끝

한국에서 따로 할 일

  • 게임은 나오기 전에 등급분류를 받아야 하는데, 구글 플레이와 앱스토어는 스스로 등급을 매기는 사업자라 스토어의 등급 설문으로 끝나요. 플레이에서는 전체·12·15·19로 표시돼요. (구글 공식, 애플은 뉴스 기준)
  • 2026-11-02부터 모바일 게임 등급분류 업무가 민간(게임콘텐츠등급분류위원회)으로 넘어갔어요. 개인 개발자에게 바뀌는 점은 아직 공식 안내를 못 찾았어요. (뉴스)
  • 무료이고 광고·결제가 없으면 통신판매업 신고는 보통 필요 없어요. 광고나 인앱결제를 넣으면 사업자등록과 통신판매업 신고가 생길 수 있어요. (블로그 기준, 공식 확인 못 함)

아직 확인 못 한 것

  • 애플 개발자 프로그램의 원화 금액과 가입 승인에 걸리는 시간
  • 등급분류 민간 이관 뒤 개인 개발자가 따로 할 일
  • Capacitor 8이 기본으로 API 36을 타깃하는지, 안드로이드 15 이상 화면 가장자리에서 안전 영역이 맞는지(실제 폰에서 확인)
  • 로그인이 랭킹에만 쓰여도 애플 4.8이 걸리는지(안전하게 애플 로그인을 넣는 쪽으로 정함)
  • 구글 프로덕션 심사에 걸리는 날짜(공식 숫자 없음)
