## 먼저 볼 것

| 작품 | 폴더 | 무엇 | 상태 |

나머지는 사이트 첫 화면의 '전체' 탭에 있어요.

## 어떻게 만들었나

코드는 대부분 AI(Claude Code)가 썼어요. 저는 무엇을 만들지 정하고, 직접 써 보며 고칠 곳을 짚고, 시험과 화면으로 맞는지 확인했어요. 팀 과제(덜미)는 누가 무엇을 했는지 `secure-msg/log/`에 항목마다 적어 두었어요.

- 프레임워크 없이 HTML·CSS·JS로 만들었고, 일부는 Firebase(랭킹·게시판·커플 앱)를 써요.
- 게임 원본(Godot·Unity 프로젝트)은 이 저장소 밖에 있어요. 여기엔 웹 맛보기·기획서·도록만 있어요.
- 개인 자료는 암호화해서 올려요(`lock/`). 열쇠가 없는 기기에서는 목록에도 안 보여요.
