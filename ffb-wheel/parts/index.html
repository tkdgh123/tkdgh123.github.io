02사람별 할 일

01 기구 김도영 기구 main · 시연

평가 기준 조립 난이도, 구조 문제 해결(내구성, 공간 제약)

  1. 페달 설계페달판 크기, 회전축 위치, 밟는 각도, 압축 스프링 자리. 액셀·브레이크는 같은 틀로. 밟는 각도는 SRS 2.5대로 18도 이상.
    치수 적은 설계도
  2. 나무 재단설계도에서 자를 조각 목록을 뽑아 자르기. 실톱은 학교에서 대여.
    재단 목록, 자르기 전·후 사진
  3. 조립축이 좌우로 흔들리지 않게, 세게 밟아도 받침이 밀리지 않게 바닥 고정.
    조립 사진, 고친 점
  4. 센서 자리회전축 끝 자석과 AS5600이 마주 보게. 최민호와 같이 정하기.
    센서 자리 사진
02 HW 최민호 HW main

평가 기준 부품 종류와 수, 부품 간 연동, 회로 복잡도

  1. 센서 자리·선 길 정하기설계 단계에서 김도영과. 페달 박스에서 아두이노까지 선이 지나갈 길.
    정한 내용
  2. 센서 장착·배선AS5600 OUT을 액셀 A0, 브레이크 A1에. 5V·GND 연결, 밟아도 선이 당겨지지 않게 고정.
    배선 사진
  3. 회로도에 페달 추가기존 회로도에 페달 센서 두 개 부분.
    회로도
  4. 배선 점검시험 때 김창식과. 선을 흔들어도 값이 튀지 않는지.
    점검 결과
03 SW 황찬웅 SW main

평가 기준 제어 로직 복잡도, 부품 연동, 통신 프로토콜, 데이터 처리

  1. 센서 출력 범위 설정장착 전에 I2C로 각 AS5600을 페달 행정에 맞추기. 굽을지(BURN, 최대 3번) P 보정만 쓸지 정하기 — SRS 첨삭 5쪽 3번.
    정한 방식과 이유
  2. 페달 값 읽기A0·A1을 읽어 시리얼로 출력. V 명령으로 확인.
    코드, 시리얼 화면
  3. P 보정끝까지 밟고 떼서 0~1023으로 맞추고, S로 EEPROM에 저장.
    보정 전·후 값
04 기획/테스트 김창식 기획/테스트 main

평가 기준 다양한 상황 시험, 정상·예외 시험, 오류 재현과 원인 분석

  1. 재료·도구나무, 나사, 스프링이 재단 목록만큼 있는지 확인. 실톱·인두 대여. 재료비 추가 구매는 안 됨.
    재료 목록
  2. 페달 시험 표정상 — 끝까지 밟기·떼기, 천천히·빠르게. 예외 — 두 페달 동시에, 센서 선 뺐을 때, 여러 번 밟은 뒤 값이 밀리는지.
    시험 표
  3. 시험하고 기록결과, 생긴 문제, 원인. 문제는 다시 일으켜 보고 담당자에게.
    시험 결과
  4. 진행 동영상이번 주 만든 것을 3분 안으로 찍어 팀으로 제출.
    영상
