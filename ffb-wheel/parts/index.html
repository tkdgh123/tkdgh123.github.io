페달 완성

두 페달을 밟으면 시리얼 모니터의 값이 바뀐다.

제출 11.16 월 23:59
진행 동영상 · 주차 보고서

기구김도영
  1. 페달 조립자른 조각을 붙이고 회전축 달기
  2. 복귀 스프링압축 스프링을 달아 놓으면 제자리로
  3. 휠 베이스 수치모터, 벨트, 핸들 축 자리
자세히 보기

1차시

  1. 조각 맞대 보기붙이기 전에 설계도 자리에 놓아 보고, 수치와 다른 곳은 연필로 표시
  2. 축 구멍 표시·뚫기양쪽 받침 구멍이 일직선이 되게. 액셀·브레이크를 같은 높이로
  3. 붙이기접착제를 바르고 나사로 고정. 굳는 동안은 건드리지 않기

2차시

  1. 회전축 끼우기페달판이 손으로 걸림 없이 돌아가는지
  2. 복귀 스프링 달기페달판과 받침 사이에. 놓으면 제자리로 돌아오는지
  3. 밟아 보기끝까지 밟았을 때 황찬웅이 정한 각도만큼 가는지 각도기로
  4. 휠 베이스 수치 그리기모터, 풀리, 벨트, 핸들 축 위치와 책상에 고정할 방법

막히면

  • 축이 뻑뻑하면구멍을 조금 넓히거나 축 표면 다듬기
  • 끝까지 안 밟히면스프링 자리나 멈추는 위치 조정
  • 접착이 덜 굳었으면축·스프링 달기는 다음 차시로
준비
자른 조각, 접착제, 나사와 드라이버, 회전축 재료, 압축 스프링 2개, 각도기나 자. 구멍 뚫을 도구가 대여되는지 조교에게 먼저 확인
함께
최민호 — 축 끝 자석 자리를 구멍 뚫기 전에 / 황찬웅 — 밟는 각도
다 됐다는 기준
두 페달이 걸림 없이 돌고, 놓으면 제자리, 정한 각도만큼 밟히고, 받침이 흔들리지 않음
주의
축 구멍이 비뚤면 센서 값이 흔들려요. 액셀·브레이크를 똑같이 만들어야 보정도 같아져요
남길 것
붙이기 전·후 사진, 축과 스프링 단 사진, 밟는 영상, 고친 점, 휠 베이스 수치 그림
HW최민호
  1. 센서 장착AS5600 두 개를 축 끝 자석과 마주 보게
  2. 페달 배선OUT → A0(액셀)·A1(브레이크), 5V·GND, 선 고정
  3. 페달 회로도기존 회로도에 페달 부분 추가
자세히 보기

1차시

  1. 보드 핀 확인AS5600 보드에 적힌 핀 이름(VCC, GND, OUT, SDA, SCL 등)을 사진으로. 보드마다 이름이 조금씩 달라요
  2. 책상에서 먼저 연결페달에 달기 전 센서 하나를 브레드보드로 연결하고 자석을 손으로 돌려 값이 바뀌는지(황찬웅 코드)
  3. 자석 자리 정하기김도영과 회전축 끝 한가운데에 붙일 방법

2차시

  1. 센서 장착자석과 마주 보게, 중심을 맞춰서. 간격은 데이터시트 권장값 확인
  2. 배선아래 배선표대로
  3. 선 고정밟을 때 움직이는 쪽에 선이 걸리지 않게 받침 쪽으로
  4. 회로도기존 회로도에 페달 센서 두 개

배선표

  • 액셀 AS5600 OUT아날로그 출력A0
  • 브레이크 AS5600 OUT아날로그 출력A1
  • 두 센서 VCC전원5V
  • 두 센서 GND접지GND

막히면

  • 값이 안 바뀌면자석 중심이 어긋났는지, 간격이 먼지, OUT 핀이 맞는지
  • 값이 튀면브레드보드 접촉이 헐거운지, 선이 밟을 때 당겨지는지
  • 밟을수록 값이 작아지면고장 아님. 나중에 SW의 I 명령으로 방향을 뒤집을 수 있어요(SRS 3.1.1)

  2. 페달 값 읽기 코드A0·A1을 읽어 시리얼로 출력
자세히 보기

1차시

  1. 두 방식 비교아래 비교표를 보고 팀에 설명
  2. 방식 정하기정한 방식과 이유를 SRS 2.5에 반영(SRS 첨삭 5쪽 3번)
  3. 코드 뼈대시리얼 115200bps 시작 → 반복하며 A0·A1 읽기 → 한 줄로 출력

2차시

  1. 배선된 센서로 확인최민호 배선이 끝나면 밟아 보며 값이 바뀌는지
  2. 놓은 값·밟은 값 기록두 페달의 놓았을 때 값과 끝까지 밟았을 때 값. 12주차 보정의 기준
  3. 출력 모양 정하기김창식이 시험 표에 옮겨 적기 쉽게 액셀, 브레이크 순서로

센서 범위 방식 비교

  • 굽기(BURN)AS5600 안에 범위 저장, 최대 3번, 되돌리기 어려움전원을 꺼도 범위가 남고 코드가 단순
  • P 보정만아두이노 EEPROM에 저장, 몇 번이든 다시언제든 다시 맞출 수 있지만 코드가 늘어남

막히면

  • 값이 0이나 최댓값에 붙어 있으면배선과 센서 출력 범위 확인
  • 값이 조금씩 흔들리면지금은 기록만. 입력 필터는 2차 기능(SRS 2.6)

  2. 1차 시험끝까지 밟기·떼기, 천천히·빠르게 값 기록

  • 빠르게 밟기빠르게 여러 번값이 따라오고 튀지 않음
  • 따로 밟기액셀만, 브레이크만밟은 쪽 값만 바뀜
