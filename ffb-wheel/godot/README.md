# 운전 연습 (Godot)

창공설 레이싱 휠 팀의 운전 연습 프로그램입니다. 웹판(`../drive/`)의 도시를 Godot 4.7로 옮기고, 초보, 고령 운전자가 당황하기 쉬운 날씨와 돌발 상황을 더했습니다. 코드와 시험은 Claude(AI)가 만들었습니다.

## 실행
- 실행 파일: `build/운전연습.exe` (저장소에는 올리지 않음, 아래 명령으로 다시 만듦)
- Godot 4.7.2로 이 폴더를 열고 F5
- 실행 파일 만들기: `godot --headless --path . --export-release "Windows Desktop" build/운전연습.exe`
- 그래픽: Windows에서는 Direct3D 12로 돎 (`project.godot`의 `rendering_device/driver.windows`)

## 조작
- 간단 조작(처음 켜져 있음): W 앞으로, S 브레이크(멈춘 뒤 다시 누르면 뒤로), A D 핸들, 방향키도 됨
- 실제 조작: ↑ 가속, ↓ 브레이크, ← → 핸들, P R N D 기어, Space 주차 브레이크
- 같이 쓰는 키: Q E 방향지시등, H 비상등, F 전조등(한 번 더 누르면 상향등), C 시점, Tab 설정판, 1~8 상황 바로 일으키기

## 무엇을 연습하나 (연구 근거)
실제 도로 실력과 이어진다는 근거가 가장 강한 건 **"아직 안 보이는 위험을 미리 예측하고 그쪽을 먼저 보는" 훈련**입니다 (초보: RAPT, Pollatsek 외 2006 / 고령: 점점 어려워지는 시뮬레이터 훈련 + 피드백, Casutt 외 2014). 반응 시간만 재는 훈련은 근거가 약합니다. 그래서:
- 상황마다 **단서**를 먼저 보여 줍니다: 보도에 걸친 큰 차, 길가에서 휴대전화를 보는 사람, 굴러 나오는 공, 앞차 브레이크등, 뒷거울의 구급차.
- **아무 일도 안 일어나는 판**을 섞습니다 (아이 35%, 무단횡단 30%). 반사 신경이 아니라 "위험한 곳에서는 늘 줄이는" 습관을 기릅니다.
- 결과 카드는 ① 단서를 보고 미리 줄였는지 ② 반응 ③ 결과 순서입니다. 단서가 잘 보이던 순간의 화면에 **봤어야 할 곳을 빨간 동그라미**로 표시합니다.
- 결과는 칭찬 대신 결과로 말합니다 ("안전하게 지났어요 / 다음엔 미리 줄여요 / 위험했어요"). 짧은 기술 훈련이 과신을 키울 수 있다는 보고가 있어서입니다.
- **반응 여유**(설정판): 넉넉히 1.5초(처음, 고령) / 보통 1.0초 / 빠듯하게 0.7초. 위험이 보인 뒤 이 시간 안에 세게 밟으면 멈출 수 있는 거리에서 상황이 일어납니다.
- **연습 기록**(`user://practice.json`, 설정판 오른쪽): 상황마다 횟수, 안전 비율, 미리 줄인 비율, 처음 몇 번과 최근 몇 번의 반응 시간. 실력이 느는지 숫자로 봅니다.
- **20분마다 쉬라는 알림**: 고령자는 시뮬레이터 멀미로 30~40%가 중도에 그만둔 연구가 있어서 짧게 끊어 하도록.
- 실제 효과는 이 프로그램으로 시험한 적이 없으니 **가정**입니다. 같은 사람이 몇 주 동안 기록을 쌓으며 확인해야 합니다.

## 날씨 (설정판에서 켜고 끔)
| 날씨 | 바뀌는 것 | 지켜야 할 속도 (도로교통법 시행규칙 제19조 제2항) |
|---|---|---|
| 비 | 노면 마찰 70%, 웅덩이(한쪽 바퀴가 빠지면 핸들이 끌림, 시속 45km 넘게 두 앞바퀴가 빠지면 수막현상) | 제한 속도의 80% |
| 눈 | 노면 마찰 35%, 길에 바퀴 자국, 다른 차도 천천히 | 50% (눈 20mm 이상 쌓인 길로 봄) |
| 안개 | 가까이는 보이고 60m쯤에서 거의 안 보임 | 50% (가시거리 100m 이내) |
| 밤 | 가로등, 건물 불빛, 전조등, 맞은편 차 상향등 눈부심 | 그대로 |

계기판 왼쪽 표지가 날씨까지 계산한 제한 속도이고, 넘으면 알려 줍니다. 앞차와의 거리를 초로 보여 줍니다 (맑은 날 2초, 비, 눈, 안개는 4초보다 가까우면 빨간색).

## 레이싱 휠 붙일 때
- 입력: `scripts/main.gd`의 `read_keys()` 한 곳에서 `inp = {steer: -1~1 (왼쪽 +), thr: 0~1, brk: 0~1}`를 채웁니다. 휠 값을 여기에 넣으면 됩니다. 키보드로는 핸들, 페달 감각(운동 기술)을 익힐 수 없어서, 휠과 페달이 붙어야 이 프로그램의 목적에 맞습니다.
- 핸들에 줄 힘: `scripts/car.gd`의 `ffb` (-1~1, + = 핸들을 왼쪽으로 돌리는 힘). 타이어가 버티는 힘만큼 제자리로 돌아오려 하고, 빙판이나 수막현상에서 앞바퀴가 미끄러지면 가벼워지며, 웅덩이와 연석에서 끌리거나 떨립니다.

## 파일
- `scripts/car.gd` 차 움직임 (자전거 모델, 자동변속, 노면 마찰과 미끄러짐, 핸들 힘)
- `scripts/city.gd` 도시, 신호, 다른 차와 보행자, 공사 구간, 웅덩이와 빙판 자리
- `scripts/weather.gd` 날씨와 법정 감속 / `scripts/events.gd` 상황, 단서, 결과 / `scripts/hud.gd` 화면 / `scripts/sound.gd` 소리
- `tests/` 시험 (모두 `-- mute`를 붙이면 소리와 기록 저장을 끔)
  - `run.gd`: 봇이 달리며 상황마다 결과 (`case=sit|antic|amb|static|rules|drive|all`). `antic`은 미리 줄이는 봇과 아닌 봇을 비교
  - `soak.gd`: 10분 동안 날씨, 상황, 조작을 무작위로 바꾸며 멈춤, NaN, 끝나지 않는 상황, 다른 차 수를 봄
  - `unit.gd`, `keys.gd`: 쉼 알림, 앞차 거리, 날씨 감속, 기록 요약, 실제 키 입력
