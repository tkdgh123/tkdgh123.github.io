# 운전 연습 (Godot)

창공설 레이싱 휠 팀의 운전 연습 프로그램입니다. 웹판(`../drive/`)의 도시를 Godot 4.7로 옮기고, 초보, 고령 운전자가 당황하기 쉬운 날씨와 돌발 상황을 더했습니다. 11-24에 서울 두 동네를 본뜬 지도, 파제카 매직 공식 타이어, 실감 나는 충돌, 운전석 시점(의자 조절, 마우스로 고개 돌리기)을 더했습니다. 코드와 시험은 Claude(AI)가 만들었습니다.

## 실행
- 실행 파일: `build/운전연습.exe` (저장소에는 올리지 않음, 아래 명령으로 다시 만듦)
- Godot 4.7.2로 이 폴더를 열고 F5
- 실행 파일 만들기: `godot --headless --path . --export-release "Windows Desktop" build/운전연습.exe`
- 그래픽: Windows에서는 Direct3D 12로 돎 (`project.godot`의 `rendering_device/driver.windows`)

## 웹판 (창업실 창공설 페이지 05 실감 운전 연습, `../play/`)
- 만들기: `godot --headless --path . --export-release "Web" ../play/index.html` (스레드 없는 웹 틀이라 GitHub Pages에서 그대로 돎)
- 웹은 컴퓨터 글꼴을 못 읽어서 `fonts/NotoSansKR-Bold-sub.ttf`(Noto Sans KR 굵게, 코드에 쓴 글자와 완성형 2350자만 남김, 0.5MB)를 씀
- 크롬의 웹 그래픽(D3D11 변환)은 Godot 셰이더 하나를 준비하는 데 수 초가 걸림. 처음 그대로 내보내면 첫 화면까지 약 105초, 처음 부딪힐 때 또 수십 초 멈췄음. 그래서 웹판만 이렇게 바꿈:
  - 조명을 정점 단위로 계산 (`project.godot`의 `force_vertex_shading.web`). 첫 화면 준비가 약 20~60초로 줄어듦(노트북이 바쁠수록 김)
  - 그러면 바닥에 전조등, 가로등 불빛 웅덩이가 안 생겨서 바닥에 흐린 빛 판을 깔아 대신함 (`Kit.glow_quad`)
  - 부딪힘 효과(유리, 파편, 불꽃, 먼지, 은행잎, 연기, 물기둥, 물튀김)는 CPU 입자로 바꿈 (`Crash.web_cpu`). 입자 계산 셰이더가 하나에 10~25초 걸려서. CPU 입자는 땅 충돌과 난류가 없어 파편이 땅을 뚫고 사라짐
  - 소리는 웹 기본(샘플 재생)에선 직접 만든 소리가 안 나서 스트림 재생으로 (`default_playback_type.web`)
  - 준비하는 동안 페이지에 안내 글을 띄우고, 첫 장면을 그린 뒤 지움 (`export_presets.cfg`의 `html/head_include`, `main.gd`의 `godotReady`)
- 키보드가 있어야 함 (휴대폰에선 조작 못 함)

## 조작
- 간단 조작(처음 켜져 있음): W 앞으로, S 브레이크(멈춘 뒤 다시 누르면 뒤로), A D 핸들, 방향키도 됨
- 실제 조작: ↑ 가속, ↓ 브레이크, ← → 핸들, P R N D 기어, Space 주차 브레이크
- 같이 쓰는 키: Q E 방향지시등, H 비상등, F 전조등(한 번 더 누르면 상향등), V 와이퍼, C 시점(3인칭, 운전석, 위), Backspace 차 고치고 가까운 길로, Tab 설정판, 1~8 상황 바로 일으키기
- 운전석 시점: T G 의자 높이. 설정판의 "운전석 의자"에서 높이, 앞뒤, 등받이. 간단 조작일 때는 마우스로 고개를 돌려 옆과 사각지대를 보고(1초 가만두면 앞으로 돌아옴), 마우스 휠로 의자 높이를 바꿈. 마우스가 풀리면 화면을 한 번 누르면 다시 잡힘
- 키보드 핸들: 빠를수록 덜 꺾임 (누르면 옆 쏠림 0.35G 안쪽, 0.8초 넘게 누르면 0.55G까지). 실제 운전에서 차로를 바꿀 때 0.1~0.3G라서

## 지도 (설정판 맨 위에서 고름, 바꾸면 도시를 새로 지음)
| 지도 | 본뜬 곳 | 특징 |
|---|---|---|
| 강남역 | 강남대로와 테헤란로가 만나는 사거리 | 유리 업무 빌딩, 층마다 간판이 붙은 상가, 사거리 전광판, 2호선 출입구 넷, 노란 은행나무, 보행자 울타리, 파란 이정표(신논현, 양재, 역삼, 서초), 과속 단속 카메라, 시내버스와 택시, 바깥은 아파트 단지, 북쪽 산 위에 남산 타워 |
| 숭실대입구 | 상도로와 숭실대 정문 | 상도로만 왕복 4차로이고 남북 길은 왕복 2차로 동네길, 길 밖은 언덕(옹벽), 초록 방수 칠 지붕의 벽돌 빌라와 이름판, 대학가 가게(복사 제본, 원룸 전세, 학사 주점), 숭실대 정문과 캠퍼스, 7호선 출입구, 전봇대와 전선, 마을버스, 남쪽에 관악산 |

길 그물(교차로, 신호, 상황이 일어나는 자리)은 두 지도가 같고, 길 종류와 꾸밈이 다릅니다. 실제 지도와 거리, 건물 위치는 맞추지 않았습니다(분위기만 본뜸).

## 타이어 (파제카 매직 공식)
`scripts/car.gd`. 앞바퀴 굴림 승용차(1300kg)의 동역학 자전거 모형입니다. 앞뒤 축마다 슬립각(바퀴가 향한 쪽과 실제로 가는 쪽의 차이)과 슬립률(바퀴 둘레 속도와 차 속도의 차이)을 구해 `F = D sin(C atan(B x - E (B x - atan(B x))))`로 옆 힘과 앞뒤 힘을 내고, 둘을 합친 힘은 마찰원(D = 노면 마찰 x 바퀴를 누르는 무게)을 넘지 못합니다. 바퀴 회전 속도를 따로 계산해서 세게 밟으면 헛돌고, ABS가 바퀴 잠김을 막습니다. 브레이크를 밟으면 앞으로 무게가 쏠려 앞바퀴가 더 버팁니다. 바퀴 계산은 1초에 960번.
- 계수 [B, C, E]: 옆 앞 [10, 1.45, -0.6], 옆 뒤 [13, 1.5, -0.6] (뒤가 조금 더 버텨 한계에서 앞이 먼저 밀림), 앞뒤 [11, 1.65, 0.1]
- 핸들 힘 = 앞바퀴 복원 토크 (옆 힘 x 뉴매틱 트레일). 최대 옆 힘 근처에서 트레일이 줄어 핸들이 가벼워짐
- 확인 (`tests/tire.gd`): 시속 50km 급제동 마른 길 11.0m, 비 13.7m, 눈 26.6m, 빙판 83.1m / 최소 회전 반경 5.4m / 시속 50km에서 옆 1.0G 넘으면 앞이 밀리고 핸들 힘이 0.62 → 0.32 / 빙판에서 꺾으면 앞이 완전히 밀림 / 눈길에서 끝까지 밟으면 앞바퀴 헛돎

## 부딪힘
`scripts/crash.gd`. 겹친 방향으로 밀어내고 그 방향 속도만 되튀김 계수만큼 뒤집으며, 부딪힌 점이 무게 중심에서 벗어난 만큼 돕니다.
- 건물, 기둥, 나무, 신호등: 단단함 (나무는 흔들리고 은행잎이 떨어짐). 긁고 지나가면 불꽃
- 가로등(시속 20km 넘게), 표지판, 보행자 울타리, 라바콘, 소화전(물기둥): 넘어지거나 날아감
- 다른 차, 세워 둔 차: 무게(승용차 1300kg, 버스 11톤)로 충격량을 나눠 밀려나고 돌며, 비상등을 켜고 섬. 운전자가 멀리 가면 견인된 셈으로 다시 차로에
- 사람: 느리면 밀려 넘어지고, 빠르면 보닛 위로 올라갔다 앞으로 떨어져 누움 (피 같은 표현은 없음)
- 내 차: 부딪힌 쪽(앞, 뒤, 왼, 오)이 찌그러지고 칠이 긁힘, 앞이 많이 찌그러지면 전조등이 깨지고 연기, 핸들이 한쪽으로 쏠림. 시속 25km 넘게 앞으로 부딪히면 에어백, 시속 32km 넘으면(사람은 25km) 앞유리에 금
- 유리 파편, 검은 조각, 먼지, 화면 흔들림, 큰 충돌은 0.35초 느리게, 쿵 + 찌그러지는 소리 + 유리 소리
- 결과 카드: 충돌 속도와 "몇 m 높이(아파트 몇 층)에서 떨어지는 것과 같은 충격" (높이 = 속도² / 2g)

## 실감을 더한 것
- 운전석: 계기판 바늘, 앞기둥과 가운데 기둥(고개를 돌리면 사각지대), 실내 거울과 좌우 사이드미러(각각 따로 비춤), 손과 팔(핸들과 함께 돎), 가운데 화면에 지금 길 이름
- 비: 앞유리에 빗방울이 맺히고(뒤 풍경이 굴절돼 보임) 와이퍼가 닦은 자리만 지워짐. 눈은 눈송이
- 몸: 브레이크를 밟으면 앞으로, 커브에서는 바깥으로 쏠리고 노면에 따라 흔들림
- 미끄러질 때 타이어 자국과 끽 소리, 속도에 따른 바람 소리, 노면 소리
- 다른 차: 세단, SUV, 택시, 시내버스, 마을버스 모양 (보닛, 앞유리, 트렁크, 휠, 사이드미러)
- 사람: 팔다리를 흔들며 보도를 걷고, 11월이라 긴 패딩이 많음. 정류장에서 버스를 기다림
- 노면: 보도블록, 덧씌운 자리, 바퀴 자국, 맨홀, 정지선 앞 화살표, 보행자 신호등

## 무엇을 연습하나 (연구 근거)
실제 도로 실력과 이어진다는 근거가 가장 강한 건 **"아직 안 보이는 위험을 미리 예측하고 그쪽을 먼저 보는" 훈련**입니다 (초보: RAPT, Pollatsek 외 2006 / 고령: 점점 어려워지는 시뮬레이터 훈련 + 피드백, Casutt 외 2014). 반응 시간만 재는 훈련은 근거가 약합니다. 그래서:
- 상황마다 **단서**를 먼저 보여 줍니다: 보도에 걸친 큰 차, 길가에서 휴대전화를 보는 사람, 굴러 나오는 공, 앞차 브레이크등, 뒷거울의 구급차.
- **아무 일도 안 일어나는 판**을 섞습니다 (아이 35%, 무단횡단 30%). 반사 신경이 아니라 "위험한 곳에서는 늘 줄이는" 습관을 기릅니다.
- 결과 카드는 ① 단서를 보고 미리 줄였는지 ② 반응 ③ 결과 순서입니다. 단서가 잘 보이던 순간의 화면에 **봤어야 할 곳을 빨간 동그라미**로 표시합니다.
- 결과는 칭찬 대신 결과로 말합니다 ("안전하게 지났어요 / 다음엔 미리 줄여요 / 위험했어요"). 짧은 기술 훈련이 과신을 키울 수 있다는 보고가 있어서입니다.
- **반응 여유**(설정판): 넉넉히 1.5초(처음, 고령) / 보통 1.0초 / 빠듯하게 0.7초. 위험이 보인 뒤 이 시간 안에 세게 밟으면 멈출 수 있는 거리에서 상황이 일어납니다.
- **연습 기록**(`user://practice.json`, 설정판 오른쪽): 상황마다 횟수, 안전 비율, 미리 줄인 비율, 처음 몇 번과 최근 몇 번의 반응 시간. 실력이 느는지 숫자로 봅니다.
- **20분마다 쉬라는 알림**: 고령자는 시뮬레이터 멀미로 30~40%가 중도에 그만둔 연구가 있어서 짧게 끊어 하도록.
- 실제 효과는 이 프로그램으로 시험한 적이 없으니 **가정**입니다. 같은 사람이 몇 주 동안 기록을 쌓으며 확인해야 합니다.

## 레이싱 휠 붙일 때
- 입력: `scripts/main.gd`의 `read_keys()` 한 곳에서 `inp = {steer: -1~1 (왼쪽 +), thr: 0~1, brk: 0~1}`를 채웁니다. 휠 값을 여기에 넣으면 됩니다. 키보드로는 핸들, 페달 감각(운동 기술)을 익힐 수 없어서, 휠과 페달이 붙어야 이 프로그램의 목적에 맞습니다.
- 핸들에 줄 힘: `scripts/car.gd`의 `ffb` (-1~1, + = 핸들을 왼쪽으로 돌리는 힘). 타이어가 버티는 힘만큼 제자리로 돌아오려 하고, 빙판이나 수막현상에서 앞바퀴가 미끄러지면 가벼워지며, 웅덩이와 연석에서 끌리거나 떨립니다.

## 파일
- `scripts/car.gd` 차 움직임 (동역학 자전거 모형, 파제카 타이어, 바퀴 회전, ABS, 자동변속, 핸들 힘)
- `scripts/city.gd` 길 그물, 신호, 다른 차(밀려난 차 포함)와 보행자, 보도를 걷는 사람, 공사 구간, 웅덩이와 빙판 자리, 부딪히는 물체 격자
- `scripts/dress.gd` 지도 꾸미기: 건물(길을 따라 줄지어), 간판(글씨를 한 장에 그려 붙임), 가로수, 가로등, 정류장, 역 출입구, 이정표, 울타리, 전봇대, 언덕, 먼 산
- `scripts/models.gd` 차(단면을 이어 붙인 몸체)와 사람 모양 / `scripts/crash.gd` 부딪힘 / `scripts/cockpit.gd` 운전석, 의자, 고개, 거울, 와이퍼
- `shaders/` 건물(모양마다 창 무늬), 간판, 전광판, 차(찌그러짐, 긁힘), 앞유리(빗방울, 와이퍼, 금), 땅(보도블록, 언덕)
- `scripts/weather.gd` 날씨와 법정 감속 / `scripts/events.gd` 상황, 단서, 결과 / `scripts/hud.gd` 화면 / `scripts/sound.gd` 소리
- `tests/` 시험 (모두 `-- mute`를 붙이면 소리와 기록 저장을 끔)
  - `run.gd`: 봇이 달리며 상황마다 결과 (`case=sit|antic|amb|static|rules|drive|all`). `antic`은 미리 줄이는 봇과 아닌 봇을 비교
  - `soak.gd`: 10분 동안 날씨, 상황, 조작을 무작위로 바꾸며 멈춤, NaN, 끝나지 않는 상황, 다른 차 수를 봄
  - `unit.gd`, `keys.gd`: 쉼 알림, 앞차 거리, 날씨 감속, 기록 요약, 실제 키 입력
  - `tire.gd`: 타이어 숫자 (제동 거리, 회전 반경, 옆 쏠림, 미끄러짐) / `real.gd`: 지도마다 시점, 비, 밤, 부딪힘 장면을 찍음 (`map=gangnam|ssu`) / `perf.gd`: 초당 화면 수 (`quick view=1`) / `prof.gd`: 부분마다 걸리는 시간 / `check.gd`: 스크립트 오류
