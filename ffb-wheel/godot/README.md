# 운전 연습 (Godot)

창공설 레이싱 휠 팀의 운전 연습 프로그램입니다. 웹판(`../drive/`)의 도시를 Godot 4.7로 옮기고, 초보 운전자가 당황하기 쉬운 날씨와 돌발 상황을 더했습니다. 코드와 시험은 Claude(AI)가 만들었습니다.

## 실행
- 실행 파일: `build/운전연습.exe` (저장소에는 올리지 않음, 아래 명령으로 다시 만듦)
- Godot 4.7.2로 이 폴더를 열고 F5
- 실행 파일 만들기: `godot --headless --path . --export-release "Windows Desktop" build/운전연습.exe`
- 그래픽: Windows에서는 Direct3D 12로 돎 (`project.godot`의 `rendering_device/driver.windows`)

## 조작
- 간단 조작(처음 켜져 있음): W 앞으로, S 브레이크(멈춘 뒤 다시 누르면 뒤로), A D 핸들, 방향키도 됨
- 실제 조작: ↑ 가속, ↓ 브레이크, ← → 핸들, P R N D 기어, Space 주차 브레이크
- 같이 쓰는 키: Q E 방향지시등, H 비상등, F 전조등(한 번 더 누르면 상향등), C 시점, Tab 날씨와 상황 설정, 1~8 상황 바로 일으키기

## 날씨 (설정판에서 켜고 끔)
| 날씨 | 바뀌는 것 |
|---|---|
| 비 | 노면 마찰 70%, 길이 젖어 어두워짐, 웅덩이(한쪽 바퀴가 빠지면 핸들이 끌림, 시속 45km 넘게 두 앞바퀴가 빠지면 수막현상) |
| 눈 | 노면 마찰 35%, 길에 바퀴 자국, 다른 차도 천천히 |
| 안개 | 가까이는 보이고 60m쯤에서 거의 안 보임 |
| 밤 | 가로등, 건물 불빛, 전조등, 맞은편 차 상향등 눈부심 |

## 상황
| 번호 | 상황 | 결과 카드에 나오는 것 |
|---|---|---|
| 1 | 아이가 뛰어듦 (보도에 걸쳐 세운 승합차 앞) | 반응 시간, 아이 앞 몇 m에서 멈췄는지 |
| 2 | 무단횡단 | 미리 줄였는지, 사람 앞 거리 |
| 3 | 앞차 급정거 | 반응 시간, 앞차와 가장 가까웠던 거리 |
| 4 | 끼어들기 (왕복 4차로, 사각지대에서) | 반응 시간, 가장 가까웠던 거리 |
| 5 | 구급차 | 비켜 줬는지, 구급차가 뒤에서 기다린 시간 |
| 6 | 공사 구간 (시험장 앞 큰길) | 방향지시등, 지날 때 속도 |
| 7 | 뒤차 경적 | (당황하지 않기) |
| 8 | 빙판길 (순환로 굽은 곳 넷, 큰길 한 곳) | 들어갈 때 속도, 미끄러졌는지 |

상황은 "1초 안에 반응해 세게 밟으면 멈출 수 있는" 거리에서 일어나게 맞췄습니다 (미끄러운 날은 그만큼 멀리서).

## 레이싱 휠 붙일 때
- 입력: `scripts/main.gd`의 `read_keys()` 한 곳에서 `inp = {steer: -1~1 (왼쪽 +), thr: 0~1, brk: 0~1}`를 채웁니다. 휠 값을 여기에 넣으면 됩니다.
- 핸들에 줄 힘: `scripts/car.gd`의 `ffb` (-1~1, + = 핸들을 왼쪽으로 돌리는 힘). 타이어가 버티는 힘만큼 제자리로 돌아오려 하고, 빙판이나 수막현상에서 앞바퀴가 미끄러지면 가벼워지며, 웅덩이와 연석에서 끌리거나 떨립니다. 화면 아래 "핸들에 오는 힘" 막대가 이 값입니다.

## 파일
- `scripts/car.gd` 차 움직임 (자전거 모델, 자동변속, 노면 마찰과 미끄러짐, 핸들 힘)
- `scripts/city.gd` 도시, 신호, 다른 차와 보행자, 공사 구간, 웅덩이와 빙판 자리
- `scripts/weather.gd` 날씨 / `scripts/events.gd` 상황과 결과 / `scripts/hud.gd` 화면 / `scripts/sound.gd` 소리
- `tests/` 시험: `godot --headless --path . -s res://tests/run.gd -- mute case=all` (봇이 달리며 상황마다 결과를 출력)
