1주차 인공지능과 LLM

시험에 나오는 것

인공지능 ⊃ 머신러닝 ⊃ 딥러닝

인공지능(AI)은 인간의 지능을 모방해 컴퓨터가 학습·추론·문제 해결·의사결정·지각·언어 이해 같은 지적 활동을 하게 하는 기술이에요. 1956년 다트머스 학회에서 존 매카시가 'Artificial Intelligence'라는 말을 처음 제안했어요.

머신러닝은 데이터로 스스로 학습하는 AI, 딥러닝은 여러 층의 인공신경망을 쓰는 머신러닝이에요.

머신러닝 학습 방식뜻예
지도학습정답(레이블)이 있는 데이터로 학습해 출력을 예측회귀, 분류(SVM, 의사결정나무)
비지도학습정답 없는 데이터에서 구조·패턴을 찾음군집화(K-means), 차원 축소(PCA)
강화학습보상을 최대화하도록 행동을 학습 (에이전트·행동·보상·상태·환경)Q-Learning, DQN
딥러닝 모델쓰임
CNN합성곱으로 이미지·영상의 특징 추출 → 이미지 인식, 영상 분류
RNN / LSTM순서 있는 데이터를 기억 → 시계열 예측, 자연어 처리
Transformer자기 주의(Self-Attention)로 긴 문맥 처리 → 자연어 처리, 생성형 AI
기타GAN, Autoencoder

AI의 주요 기능 5가지는 학습 능력, 추론 및 문제 해결, 자동화 및 자율성, 자연어 처리(NLP), 컴퓨터 비전(CV)이에요.

생성형 AI와 LLM

생성형 AI

기존 데이터를 학습해 텍스트·이미지·음악·영상·코드 같은 새 콘텐츠를 만드는 기술. 창의적 생성, 프롬프트 기반 동작, 멀티모달, 자동화와 맞춤형 생성이 특징이에요.

LLM (대규모 언어 모델)

방대한 텍스트로 언어의 패턴과 문맥을 학습해 텍스트를 이해·생성하는 모델. ChatGPT(OpenAI), Gemini(Google), Claude(Anthropic), Copilot(Microsoft).

LLM의 한계와 보완 기술

한계보완 기술
환각(Hallucination), 지식의 시점 제약RAG
특정 분야의 정확도 부족파인튜닝
답변 품질의 불안정성프롬프트 엔지니어링
계산 수행, 실시간 정보 활용의 한계함수 호출, MCP
복잡한 다단계 작업의 어려움AI 에이전트, 랭그래프(LangGraph)
편향, 출처의 불투명성, 윤리 문제기술만으로는 해결 불가 → 사람의 검증

단답형은 아래 설명을 주고 이름을 쓰게 해요. 왼쪽 이름을 가리고 설명만 보고 떠올려 보세요.

이름설명
프롬프트 엔지니어링답을 잘 받도록 입력 프롬프트를 설계하는 것. 모델에게 주는 업무 매뉴얼(지시문)
파인튜닝이미 학습된 모델에 특정 분야 데이터를 추가로 학습시키는 기법. 처음부터 만들 때보다 시간·비용이 적음
랭체인여러 LLM·검색·도구를 표준화된 방식으로 조립하는 개발 프레임워크. 모델을 바꿀 때 선언부만 바꾸면 됨
RAG질문이 오면 외부 문서·DB에서 관련 정보를 검색해 그걸 바탕으로 답을 생성 (최신·내부·전문 자료)
랭그래프여러 AI 에이전트의 작업 흐름을 그래프로 설계하는 프레임워크 (조건 분기, 반복, 협업)
AI 에이전트목표를 분석해 스스로 계획하고 도구를 골라 실행한 뒤 결과를 검토하며 반복·개선 (예: 부산 출장 계획)
함수 호출외부 API나 직접 만든 함수를 호출해 그 결과로 답하게 하는 기술
MCPAI 앱이 파일·DB·API·웹 서비스와 표준화된 방식으로 연결되게 하는 개방형 프로토콜

2주차 빅데이터와 리스트

시험에 나오는 것

  • 데이터 분석 프로세스의 순서와 단계마다 하는 일 구분 (특히 전처리와 탐색적 분석)
  • 리스트·딕셔너리, 특히 2차원 리스트. 넘파이는 안 나와요.

데이터 → 정보 → 지식 → 지혜

데이터현실에서 측정·수집한 사실이나 값 (기호, 문자, 숫자의 조합)
정보목적에 맞게 데이터를 가공·처리한 것
지식정보를 해석하고 의미를 부여해 구조화·일반화한 것
지혜지식과 경험으로 내리는 최선의 판단과 행동, 창의적인 아이디어

데이터 과학은 프로그래밍(해킹 스킬) + 수학·통계 + 해당 분야 전문성을 함께 써서 데이터로 문제를 푸는 융합 학문이에요.

빅데이터의 5V

기존 데이터베이스로는 수집·저장·분석이 어려울 만큼 방대한 데이터예요. 디지털화 → 인터넷·모바일 → SNS → IoT → 클라우드가 이어지며 생겨났어요.

5V뜻예
Volume 규모매우 방대한 양수백만 건의 쇼핑 데이터, 센서 데이터
Velocity 속도생성·수집·처리 속도가 매우 빠름실시간 SNS 게시글, 주식 거래
Variety 다양성정형·반정형·비정형 등 다양한 형태텍스트, 이미지, 음성, 영상
Veracity 신뢰성정확성·품질 확보오류·중복 데이터 관리
Value 가치분석으로 가치 창출맞춤 추천, 매출 예측

데이터 분석 프로세스 6단계

순서하는 일
① 문제 정의분석 목표 설정, 해결할 문제 정의, 분석 범위 결정
② 데이터 수집데이터 원천 파악, 수집, 저장 (공공 데이터)
③ 전처리정제·변환: 여과, 정제(결측치·중복·이상치 처리), 통합, 축소, 변환
④ 탐색적 분석 (EDA)살펴보며 이해: 기초 통계 확인, 분포 분석, 변수 간 관계 분석, 이상치 탐색, 그래프
⑤ 시각화 및 활용결과를 시각적으로 표현해 의사결정에 활용 (대시보드, 보고서)
⑥ 결과 해석 및 평가결과를 정리해 발표, 의미 있는지 판단

헷갈리는 것: 이상치를 찾아보는 건 탐색적 분석, 고치거나 지우는 건 전처리예요.

리스트: 인덱스와 슬라이싱

리스트[시작:끝:간격]에서 끝 번호는 포함하지 않아요. 음수 인덱스는 뒤에서부터 세요.

2차원 리스트: 리스트[행][열]

실습: 학생 이름과 세 과목 점수로 총점·평균 구하기

딕셔너리: 키로 찾고, 키로 넣어요

3주차 판다스로 불러오기

시험에 나오는 것

  • 정형·반정형·비정형 구분: 종류가 다른 것 고르기, 해당하는 것 찾기
  • 판다스 시리즈와 데이터프레임 만드는 코드 (판다스 코드와 결과 그림이 나와요)
  • read_csv · read_excel 쓰는 법과 옵션 구분: header, skiprows, sep, encoding, thousands
  • 숫자 속 쉼표(,)도 문자라 문자열로 읽혀요. astype으로 바꿀 수도 있지만 옵션(thousands=',')으로도 숫자가 돼요. 코드에 밑줄을 긋고 무슨 옵션인지 물을 수 있어요.

정형 · 반정형 · 비정형

종류뜻예
정형정해진 형식과 구조(행과 열)로 저장관계형 DB 테이블, 스프레드시트(엑셀), CSV, 고객 정보·주문 내역
반정형고정 필드는 아니지만 구조 정보(태그·계층)를 데이터와 함께 제공XML, HTML, JSON, 웹 문서, 웹 로그
비정형정해진 구조가 없어 그대로는 질의 처리를 못 함, 분석 전 전처리 필요소셜 데이터, 텍스트 문서, 이미지·동영상·음성, PDF, 이메일

서울 열린데이터광장에서 내려받을 때 Sheet(CSV)는 정형, OpenAPI(JSON)는 반정형이에요.

행(row) = 레코드, 열(column)은 분야마다 변수(Variable)·속성(Attribute)·특징(Feature)이라고도 불러요.

열에 담긴 데이터판다스 자료형예
수치형 (정량적)int64 정수, float64 실수키 175, 몸무게 50.4
범주형 (정성적)object 텍스트, category, bool상품리뷰, 성별, 혈액형
시간형datetime64생일 2008-1-3

4주차 정보 확인과 선택

시험에 나오는 것

  • info() 해석: 행과 열 개수, 결측치가 있는 열 이름, 수치형과 범주형 개수 (범주형에는 object도 category도 들어가요)
  • describe() 해석: 수치형이면 평균·표준편차 같은 통계, object면 고유한 값의 개수(unique)·가장 많은 값(top)·빈도수(freq). 해석을 찾아서 써요.
  • 같은 선택도 표기법에 따라 달라요. 대괄호로 쓰면 열이 먼저, 행이 나중 df['열'][행]
  • loc은 이름(라벨): 열은 문자열만, 행 자리는 인덱스 이름으로 이해. iloc은 파이썬처럼 위치 번호: 열 이름(문자) 못 씀
  • 열 이름 변경(rename), 행 번호 재설정(reset_index), 정렬(sort_values), 삭제(drop): 형식까지 구분, 예제를 놓고 결과 고르기. 정렬은 예제에서 쓴 형식으로.
  • 결측치: isnull()/isna().sum()으로 개수, 지우기보다 fillna()로 채우기를 많이 써요 (평균, 중앙값, 0, 문자).

loc과 iloc: 같은 행을 고르는 두 가지 형식

loc[행, 열] · 이름(Label)

iloc[행, 열] · 위치 번호

행·열 모두 정수 위치. 열 이름을 쓰면 오류. 슬라이싱 끝 미포함 (파이썬과 같음).

인덱스를 문자로 바꿔 보면 loc이 '이름'으로 고른다는 게 더 잘 보여요.

6주차 concat과 merge

시험에 나오는 것

  • 결과 그림 중심: 행 단위로 연결했는지, 열 단위로 연결했는지 실습한 결과를 보고 구분
  • axis=0은 행 방향(위아래), axis=1은 열 방향(좌우)
  • merge는 기준이 되는 열이 있어야 결합돼요.
  • 결과를 보고 merge를 한 건지 concat을 한 건지 구분할 줄 알아야 해요.
함수기준결과에서 알아보는 법
pd.concat([df1, df2])그냥 위아래로 이어 붙임 (axis=0)행이 늘고 인덱스가 겹쳐요 (0, 1, 0, 1)
pd.concat([df1, df2], axis=1)좌우로 이어 붙임같은 열 이름이 두 번 나와요
pd.merge(df1, df2, on='열')공통 열(키) 값이 같은 행끼리기준 열은 한 번만, 나머지 열이 옆에 붙어요
df1.join(df2, lsuffix=…, rsuffix=…)인덱스끼리겹치는 열 이름 뒤에 _접미사가 붙어요

concat: 이어 붙이기

먼저 붙일 두 표예요.

리스트 안의 변수명(test1, test2)에는 따옴표를 붙이지 않아요. 행 방향으로 붙일 땐 두 표의 열 이름을 같게 맞춘 뒤 붙여요.

merge: 기준 열로 결합

how남는 행score1(21명) + test1(2323, 2201)
inner (기본값)양쪽에 다 있는 키만2201 한 명 → 1행
left왼쪽 표의 모든 키21행, test1에 없는 학번은 출석·프로젝트가 NaN
right오른쪽 표의 모든 키2행, 2323은 분반·성별·성적이 NaN
outer양쪽 모든 키22행

join: 인덱스로 결합

실습: 교통사고 데이터로 merge, concat, 질문 답하기

질문에 답하기

그 밖에 6주차 강의안: 이상치, 중복, 형 변환

  • 사분위수: Q1(25%) · Q2(50%) · Q3(75%), IQR = Q3 − Q1, 하한 = Q1 − 1.5×IQR, 상한 = Q3 + 1.5×IQR. 예: Q1 60, Q3 80 → IQR 20 → 30 미만·110 초과가 이상치 후보.

8주차 bar, pie, subplot

시험에 나오는 것

  • pie의 옵션: 비율을 나타내는 그림이 나와요. 이름을 표시하는 옵션(labels)과 값(비율)을 표시하는 옵션(autopct)의 이름을 알아야 해요.

  • 한 화면에 여러 개: subplot / subplots, 앞쪽 위주로 행과 열의 개수, 위치값, 그 위치에 어떤 차트가 들어가는지. subplots는 [0, 0], [0, 1]처럼 넣어요.

9주차 워드클라우드

  • 워드클라우드 그림이 나와요.

  • 실행할 때마다 모양이 랜덤하게 바뀌는데, 한 번 실행하면 안 바뀌게 고정하는 속성

10주차 folium 지도

시험에 나오는 것

  • 지도 그리기 옵션: 위도·경도(location), 처음 실행할 때 확대/축소(zoom_start)
  • 마커 속성: 클릭하면 popup, 마우스를 올리면 tooltip. 값은 다 주어지고 속성 이름을 구분해요.
  • 지도에 마커클러스터 연결: add_to( ) 안에 지도가 들어가는지, 마커클러스터가 들어가는지
  • 마지막 실습 코드만 이해하면 돼요. 위도·경도를 하나씩 넣지 않고 반복문(iterrows)으로 표를 돌며 마커를 넣은 실습

folium은 자바스크립트 지도 라이브러리 Leaflet.js를 파이썬에서 쓰게 해 줘요. 코랩에 설치돼 있어요. 순서: 지도 그리기 → 마커 → 여러 위치에 마커 → MarkerCluster로 묶기.

지도 그리기: folium.Map()

속성하는 일
location=[위도, 경도]지도의 중심. 위도는 남북(적도 기준), 경도는 동서(본초 자오선 기준)
zoom_start=정수처음 그릴 때 확대 정도 (기본 10, 최대 18, 클수록 확대)
zoom_control=True왼쪽 위 +/− 버튼 (기본 True)
control_scale=False왼쪽 아래 축척 (기본 False)
tiles='스타일'지도 모양. None으로 두고 TileLayer로 따로 추가해요
width, height지도 크기

마커: popup은 클릭, tooltip은 마우스

속성하는 일
location=[위도, 경도]마커 위치
popup='문자열'마커를 클릭했을 때 나오는 메시지 (folium.Popup('…', max_width=100))
tooltip='문자열'마커에 마우스를 올렸을 때 나오는 메시지
icon=folium.Icon(color='red', icon='car', prefix='fa')마커 색(기본 blue)과 안쪽 아이콘. Font Awesome 아이콘은 prefix='fa'
.add_to(지도)만든 마커를 지도에 올림

MarkerCluster: 가까운 마커를 묶기

마커만

지도 ← 마커들

folium.Marker([…]).add_to(map)

클러스터를 쓸 때

지도 ← MarkerCluster ← 마커들

mc = MarkerCluster().add_to(map)
folium.Marker([…]).add_to(mc)

df.iterrows()는 표의 각 행을 (인덱스, 행 데이터)로 하나씩 돌려줘요. 행 데이터에서 row['위도']처럼 꺼내요.
