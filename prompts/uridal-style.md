# 우리달 느낌으로 웹앱 만들기 — 프롬프트

아래를 통째로 복사해서, 맨 위 [ ] 칸만 바꿔 쓰면 돼요.

```
[만들 것: 예) 둘이 같이 쓰는 가계부 / 친구 넷이 쓰는 여행 체크리스트 / 나 혼자 쓰는 습관 기록]
[누가 쓰나: 예) 나와 여자친구 두 명]
[꼭 있어야 할 기능: 예) 지출 적기, 이번 달 합계, 누가 냈는지 색 구분]

위 서비스를 휴대폰에서 앱처럼 쓰는 작은 웹앱(PWA)으로 만들어 줘. 느낌과 규칙은 아래와 같아.

## 느낌
- 동글동글하고 귀여운, 말랑한 파스텔. 차갑거나 사무적인 느낌, 흔한 AI 사이트 느낌은 피해.
- 사람마다 색이 있다: 예) 남자친구=하늘색, 여자친구=분홍, 함께=라벤더. 보는 사람에 따라 화면 전체 바탕 색이 바뀐다.
- 화면 맨 위는 그 서비스의 "가장 중요한 숫자 하나"를 크게 (예: D+659, 이번 달 32만 원). 그 아래 작은 한 줄 (예: 700일까지 41일).
- 대각선, 1px 테두리 격자 카드, 카드 왼쪽 색 줄무늬, 보라-파랑 그라데이션은 쓰지 마. 카드는 흰 바탕 + 아주 옅은 색 그림자, 구분은 옅은 색 면(틴트)으로.

## 모양
- 모서리: 카드 20~34px, 버튼·칩·탭은 완전한 알약 모양(999px).
- 글꼴: 제목·큰 숫자는 Jua(구글 폰트), 본문은 Pretendard. 16px 이상(아이폰 입력칸 확대 방지).
- 색은 CSS 변수로: --bg, --panel, --hero, --ink, --soft, --line, --acc, --acc-ink, --acc-soft와 사람별 --a / --b / --both. 그림자도 강조색을 섞어 옅게.
- 아래에 떠 있는 알약 모양 탭바(반투명 + 블러), 탭은 3개 이내.
- 추가·고치기는 전부 아래에서 올라오는 시트(dialog). 바깥을 누르거나 저장하면 부드럽게 내려가며 닫힌다.
- 다크 모드도 같은 결로. 테마는 휴대폰마다 고를 수 있게(오른쪽 위 작은 색 점 버튼).
- 캐릭터 테마를 넣을 때는 공식 그림을 사이트에 넣지 말고, 그 캐릭터를 떠올리게 하는 소품을 직접 그린 SVG로 (굵은 진한 외곽선 + 단색 채움, 예: 리본·사과·우유병·곰인형·물방울 무늬). 공식 사진은 앱 안에서 각자 넣게.

## 움직임
- 화면이 바뀔 때마다 살짝 떠오르며 나타나기: 투명 0→1, 아래 10px→0, 320ms, cubic-bezier(.22,1,.36,1).
- 넘기는 화면(달력 달 바꾸기 등)은 지금 것이 밀려 나가고 → 다음 것이 반대쪽에서 들어오게. 스와이프하면 손가락을 따라 움직이고, 짧게 밀면 제자리로.
- 높이가 바뀌어 아래가 덜컥 튀는 일 없게(칸 수 고정 등).
- 휴대폰 "동작 줄이기" 설정이면 애니메이션 끄기.

## 글
- 한국어, 짧고 다정하게. 설명 각주·안내 문단 넣지 말고 버튼 이름만으로 알 수 있게.
- 지우기는 두 번 눌러야(첫 번째 누르면 "한 번 더"). 결과는 아래 작은 토스트로 ("저장했어요").
- 빈 화면에는 무엇을 하면 되는지 한 문장.

## 기술
- 빌드 없이 index.html + style.css + app.js 세 파일. 라이브러리 추가 금지(필요한 건 직접 몇 줄로).
- 데이터: Firebase Firestore 무료 요금제(서울 리전), 실시간 동기화(onSnapshot), 오프라인 캐시.
- 로그인 대신 긴 무작위 코드(예: XXXX-XXXX-XXXX-XXXX-XXXX)를 아는 사람만 들어오게. 보안 규칙으로 목록 조회 금지·코드 형식만 허용. 링크(#코드)로 초대.
- manifest + service worker(network-first)로 홈 화면에 설치. GitHub Pages에 올리기.
- 처음 화면은 세로 가운데. 로딩이 멈추면 "처음 화면으로" 버튼, 앱 안 어디서든 코드 보기·초기화 가능.

## 다 만든 뒤 확인
- 휴대폰 크기 320 / 360 / 430px, 라이트·다크, 모든 테마·탭에서 가로로 넘치는 곳 없는지.
- 모든 기능(추가·고치기·삭제·두 기기 동기화)을 브라우저 자동 테스트로 눌러 보고, 콘솔 오류 0개인지.
- 휴대폰 속도(CPU 6배 느리게)에서 화면 넘길 때 끊김 없는지.
```
