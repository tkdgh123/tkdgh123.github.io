처음 한 번만

  1. GitHub 열쇠 만들기 ↗

    Repository access에서 Only select repositories → tkdgh123.github.io, 권한은 Actions: Read and write 하나만(링크가 미리 골라 둠) → 맨 아래 Generate token. 이 열쇠로는 사이트를 고칠 수 없고, 잠금 작업을 시작하는 것만 돼요.

  2. 잠금 비밀번호 등록하기 ↗

    Name에 LOCK_PASSWORD, Secret에 세 단계를 한 줄에 하나씩(비밀번호, 질문 답, 점 번호).

  3. 만든 열쇠 붙여 넣기

바꾸려면 세 단계를 다시 입력하세요. 이 기기에 저장되지 않고, 이번 요청에 서명하는 데만 써요.
