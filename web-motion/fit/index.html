카드마다 어울리는 움직임

창업실 카드 27장에 움직이는 웹사이트 기법 21개를 하나씩 맞춰 봤어요. 카드마다 딱 셋을 고르고, 1순위는 그 작품 내용으로 데모를 만들었어요. 섞는 게 나을 때만 비율을 정해 섞었어요.

고르면서 갈렸던 것

  1. 내용이 먼저, 기법은 그다음

    게임은 세계를 보여 주고, 실물(휠·페달)은 돌려 보고 뜯어 보고, 코드·설정은 직접 치는 걸 보여 줘요. 같은 3D라도 무엇을 보여 주는지가 갈랐어요.

  2. 자주 여는 도구는 가볍게

    매일 AI 공부·LMS처럼 매일 여는 카드엔 무거운 3D 비행 대신 종이 쌓기·벽돌처럼 바로 뜨는 걸 골랐어요. 첫 화면에서 3초 기다리게 하면 안 돼요.

  3. 글은 차분하게

    답안·감상문·보고서는 읽는 게 목적이라 화려한 움직임이 글을 이기면 안 돼요. 빛 하나, 커서 하나 정도만.

  4. 섞을 때만 섞음

    덜미는 터미널이라 커서가 맞지만 '보낸다'를 보여 주려면 점이 건너가야 해서 6:4. 프밍기 노트·Claude Code 안내는 커서 하나로 충분해서 섞지 않았어요.

  5. 폰에서도 되나

    지도 비행·운전은 폰에서 조작이 어려워 1순위에서 밀린 경우가 많아요. 그래서 그랑프리·밀기는 1순위 바탕이 된 카드가 없어요.

  6. 이미 사랑받은 것은 지킴

    한 학기 쌓기는 손대지 않고 생각만 빌려 새 파일에 썼어요. 점으로 그린 작품은 우리와 안 맞는다는 말 그대로 어디에도 넣지 않았어요.
